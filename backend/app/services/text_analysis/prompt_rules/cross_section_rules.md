# Cross-section rules — completeness lens prompt block

**Назначение:** запретить cross-section / cross-discipline missing
findings, когда pipeline аудитирует только один MD-документ.

Pipeline аудитирует один MD за раз. Cross-section проверки требуют
сравнения двух разделов одновременно (например, P_уст вентустановки в ОВ
vs ЭОМ-вектор нагрузок). В single-MD аудите это **невозможно** —
проверять нечего.

## Главное правило

Запрещено генерировать missing finding на:

- «**Параметры в ЭОМ не совпадают с ОВ**» — мы видим только один из них.
- «**Отсутствует ЭОМ как раздел**» — другой раздел может быть в отдельном MD.
- «**Сводный перечень разделов проекта отсутствует**» — атрибут проекта в
  целом, не одной марки.
- «**Cross-discipline requirement** missing» — single-MD pipeline не может
  установить факт отсутствия в смежном разделе.
- Любой item с `requires_cross_section=true` из metadata.

## MULTI items

MULTI-05..MULTI-13 — cross-section consistency. На одном MD проверять
**невозможно**. Все эти items должны быть **drop** даже если на странице
есть какие-то цифры.

Specifically blocked MULTI items in single-MD context:

| Item | Что сравнивает |
|---|---|
| MULTI-05 | ЭОМ ↔ ОВ (P_уст вентиляторов) |
| MULTI-06 | ЭОМ ↔ ВК (P_уст насосов) |
| MULTI-07 | ЭОМ ↔ СС (мощность стоек) |
| MULTI-08 | ОВ ↔ АПС (алгоритм ПДВ) |
| MULTI-09 | ВК ↔ АПС (противопожарная насосная) |
| MULTI-10 | АР ↔ КЖ (привязки) |
| MULTI-11 | АР ↔ КМ (фасадные узлы) |
| MULTI-12 | КЖ ↔ КМ (закладные) |
| MULTI-13 | АР ↔ ОВ/ВК/ЭОМ (проходы и отверстия) |

## Когда cross-section finding допустим

Только при явном противоречии **внутри текущего MD** (без сравнения с
другим документом):

- ✅ «На плане АР показано отверстие 200×200 без указания размера для
  задания смежнику» — нарушение внутри одного MD.
- ✅ «Насос упомянут в ВК, но без P_уст для передачи в ЭОМ» —
  параметрический пробел внутри одного MD.

## Когда cross-section finding НЕ допустим

- ❌ «Отсутствует координация с разделом X» — координация может быть в
  письме-задании, которое мы не видим.
- ❌ «Параметры разных разделов не совпадают» — нет второго раздела.
- ❌ «Согласованности нет» — не доказано отсутствием.

## Источник правды

Поле `requires_cross_section` в
`backend/app/data/discipline_checklists_metadata/<DISC>.json`.
Если runner видит этот флаг — finding **drop** независимо от severity.
