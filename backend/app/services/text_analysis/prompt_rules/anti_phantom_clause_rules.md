# Anti-phantom-clause rules — completeness lens prompt block

**Назначение:** запретить ссылки на придуманные / неподтверждённые
номера пунктов нормативов и на отменённые ГОСТы.

## Главное правило

При формулировке finding'а, если ты не можешь точно процитировать пункт
нормы (с конкретной цифрой), **НЕ указывай вымышленный номер**.

✅ Правильно:

- «СП 256.1325800.2016, раздел 6 (расчётные нагрузки)»
- «СП 256.1325800.2016 (ред. 29.01.2024)»
- «ГОСТ Р 21.101-2020»

❌ Запрещено:

- «СП 256.1325800.2016, п. 6.4» — если ты не уверен в подпунктовке;
- «СП 63.13330.2018, п. 8.1.46» — точный пункт нужно сверить;
- «ГОСТ Р 21.1101-2013» — этот ГОСТ **заменён** на ГОСТ Р 21.101-2020;
- «СанПиН 2.1.4.1074-01» — нужна верификация актуальности.

## Items, требующие верификации подпунктов

Эти items имеют `requires_human_validation=true` в metadata. Для них
finding допустим только в **shadow_mode** до подтверждения пункта:

- EOM-05 — СП 256.1325800.2016, п. 6.4
- EOM-07 — СП 256.1325800.2016, п. 8.5
- KJ-08 — СП 63.13330.2018, п. 8.1.46
- KJ-16 — СП 63.13330.2018, п. 10.3.5
- AR-08 — СП 50.13330.2012 / СанПиН 1.2.3685-21
- VK-20 — СанПиН 2.1.4.1074-01

## ПУЭ-7 — обязательная параллель

ПУЭ-7 **не зарегистрирован Минюстом** → применяется добровольно.

При ссылке на ПУЭ-7 в finding'е **ОБЯЗАТЕЛЬНО** указывай параллельную
ссылку на действующий СП:

| ПУЭ-7 | Параллельный СП |
|---|---|
| ПУЭ-7 гл. 1.7 | СП 437.1325800.2018 / ГОСТ Р 50571.5.54 |
| ПУЭ-7 разд. 7 | СП 256.1325800.2016 разд. 7 |
| ПУЭ-7 п. 1.2 | СП 256.1325800.2016 разд. 5 |
| ПУЭ-7 гл. 1.8 | ГОСТ Р 50571.16-2019 |

Без параллельной ссылки СП — finding **отбраковать** в самопроверке.
