# Грамматики КЖ

```text
железобетонная конструкция
├── оси и отметки
├── марки стен / колонн / плит / балок / закладных
├── арматура, позиции, шаг и защитный слой
├── бетон и размеры
├── план либо набор сечений
└── физическая CAD-геометрия
```

Шесть профилей: опалубочный план, план армирования, сечение армирования,
маркировочная схема, закладные детали и железобетонный узел. Одинаковые позиции в
разных координатах сохраняются раздельно. Линии арматуры не превращаются в потоковую
сеть; связь «позиция—стержень» не создаётся без выноски или отдельного правила.
