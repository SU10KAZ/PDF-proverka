# Грамматики ТХ

```text
технологическая система
├── план или физический вид
├── помещения / шахты / машиноместа
├── оборудование и его марки
├── грузоподъёмность, скорость, огнестойкость
├── отметки и размеры
└── физическая CAD-геометрия
```

Представлены семь профилей: план автостоянки, узлы автостоянки, план лифтовых шахт,
разрез лифта, оборудование лифта, строительное задание и узлы мусороудаления.
Ближайшее расположение не превращается в технологическую связь без отдельного
геометрического или маркировочного доказательства.
