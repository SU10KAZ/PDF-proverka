# Каталог этапа «Векторные графы блоков»

Это производственная поставка эталонов, правил и компактных структурных примеров.
Runtime читает только файлы из этого каталога и не зависит от `experiments/`.

Состав:

- `manifest.json` — версия и контроль полноты каталога;
- `rules.json` — правила классификации, границ блока и ранжирования эталонов;
- `disciplines/*.json` — по одному компактному набору примеров на дисциплину;
- `profiles/*.md` — человекочитаемые описания поддерживаемых профилей;
- `build_catalog.py` — ручной компилятор для выпуска новой версии каталога.

Каждый пример содержит `block_id`, профиль, подтип, русское описание, состояние
текстового слоя, оценку полноты и компактную сигнатуру эталонного графа. Исходные
PDF не требуются для работы pipeline: они являются исследовательскими материалами,
а не production-зависимостью.

Каталог используется полноценным этапом `block_context`, который в UI называется
«Векторные графы блоков». Этап создаёт `block_vector_graphs/*.json` и итоговый
`block_context_summary.json` до запуска анализа блоков.
