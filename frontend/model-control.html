Model Control

Модели и состояние LLM-сервера

Мониторинг удалённого LM Studio (OpenAI-совместимый /v1): список моделей и их возможности, здоровье эндпоинта, какие модели использует пайплайн. Управление загрузкой/выгрузкой на удалённом сервере не отдаётся — им управляет сам сервер.

Основное приложение

Сервер обработки

Через какой LLM-сервер идёт весь пайплайн (текст-enrichment + графика). Переключение переписывает .env и перезапускает backend (~5–10 с). Идущие аудиты прервутся.

Как это работает

Управление загрузкой моделей на сервере обработки.

Загрузка / выгрузка идут через сервер —. «Загрузить» поднимает модель в память с выбранным объёмом контекста, «Выгрузить» — снимает её. Оценка памяти (lms CLI) на audit-сервере недоступна — фактический расход VRAM смотрите на LLM-хосте.
