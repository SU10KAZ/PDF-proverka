# Function Lineage v2.8 — deterministic merge certificate

No model calls. A certificate distinguishes a PROVEN fact, a MISSING fact (stays UNKNOWN, never a contradiction) and a CONTRADICTED fact.

Never treated as merge evidence: score, rank, physical page number, page proximity, equal sheet title, or a lone candidate.

## How merge hypotheses are created

`{'adjacent_pages': 125}`

every merge hypothesis in the frozen corpora is generated by LEFT pages being exactly adjacent plus an equal function class; adjacency is forbidden as merge evidence, so no certificate may rest on the reason the candidate exists.
