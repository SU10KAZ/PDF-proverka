# Расчёт теплопотерь квартиры тип А, корп. 4

Это выборка только расчёта теплопотерь для одной квартиры из полного раздела ОВ.
Принципиальные схемы, спецификации, тепловые узлы — в основном разделе.

## Исходные данные

- Квартира тип А, площадь 78 м², этаж 5 из 17;
- Высота помещения 2,7 м;
- Расчётная температура внутреннего воздуха t_в = +20 °C (жилые комнаты), +25 °C (ванная);
- Расчётная температура наружного воздуха t_н = −28 °C;
- Ориентация фасада — северо-восток.

## Состав ограждений

## Учёт нагрева наружного воздуха

Расход инфильтрации (по СП 60.13330 п. 7.4.1) Q_инф = 240 Вт.

## Итого теплопотери квартиры

Q_общ = 1215 + 240 = **1455 Вт**.

## Подбор отопительных приборов

Радиаторы стальные панельные тип 22, нижнее подключение, термоклапан Danfoss RA-N.

Распределение мощности:
- Большая комната (3 окна): радиатор 1000 Вт;
- Спальня: радиатор 600 Вт;
- Кухня: радиатор 400 Вт;
- Итого Σ = 2000 Вт > Q_общ = 1455 Вт → проходит.
