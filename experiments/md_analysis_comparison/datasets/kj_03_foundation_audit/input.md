Принято: грунт основания — суглинок тугопластичный, **R = 230 кПа**, E = 18 МПа.

### Б.3. Проверка по II группе предельных состояний

P_ср = 210 кПа ≤ R = 230 кПа → проходит с запасом 10%.

Осадка S = 5,2 см (по СП 22.13330, метод послойного суммирования) < S_u = 12 см → проходит.
