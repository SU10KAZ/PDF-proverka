# Раздел ОВ. Вентиляция жилых помещений секции 2

## 1. Нормативная база

- СНиП 41-01-2003 «Отопление, вентиляция и кондиционирование воздуха»;
- ГОСТ 30494-2011;
- СанПиН 2.1.2.2645-10.

## 2. Расчёт вытяжной вентиляции квартиры (тип А, 78 м²)

Согласно СНиП 41-01-2003 норма воздухообмена для жилых помещений:
- кухни с газовыми плитами: 90 м³/ч;
- ванная: 25 м³/ч;
- совмещённый санузел: 50 м³/ч.

Кухня квартиры тип А оборудована газовой плитой, площадь кухни — 9 м².

В проекте принят расход вытяжки от кухни **60 м³/ч**.

Объём кухни: V = 9 × 2,7 = 24,3 м³. Кратность n = 60 / 24,3 = **2,47 ч⁻¹**.

## 3. Расчётный воздухообмен квартиры (таблица 3.1)

| Помещение      | Площадь, м² | L_вытяжка, м³/ч | L_приток, м³/ч |
|----------------|-------------|------------------|-----------------|
| Кухня (газ)    | 9,0         | 90               | -               |
| Ванная         | 4,5         | 25               | -               |
| Санузел        | 1,8         | 25               | -               |
| Жилые комнаты  | 50,7        | -                | 110             |
| **Итого**      | **66,0**    | **140**          | **110**         |

Дисбаланс +30 м³/ч компенсируется через инфильтрацию через окна с теплозвукоизоляционными клапанами.

## 4. Канал кухни

Канал кухни выполнен из оцинкованной стали 0,7 мм, сечение 150×200 мм. Скорость воздуха в канале при расчётном расходе 60 м³/ч составляет:

v = L / (3600 · F) = 60 / (3600 · 0,030) = **0,55 м/с**

Что ниже рекомендуемой скорости 1,5–3 м/с для вертикальных каналов жилых зданий.

## 5. Источник тепла

Источник теплоснабжения — индивидуальный тепловой пункт здания, температура теплоносителя 95/70 °C, давление 0,6 МПа. Подача теплоносителя осуществляется через узел ИТП в подвале здания.

## 6. Огнестойкость воздуховодов

Транзитные воздуховоды выполнены с пределом огнестойкости EI 30 (полиуретановая изоляция Climaflex).

## 7. Согласования

Проект согласован с разделами АР (отверстия в перекрытиях) и ЭОМ (электроприёмники вентустановок 12 кВт суммарно).
