# Раздел КМ. Стропильная ферма ФС-1 пролётом 18 м

## 1. Нормативная база

Расчёт выполнен в соответствии с:
- **СНиП II-23-81*** «Стальные конструкции»;
- СП 20.13330.2016 «Нагрузки и воздействия»;
- ГОСТ 27772-2015 «Прокат для строительных стальных конструкций».

## 2. Исходные данные

- Пролёт фермы L = 18,0 м;
- Шаг ферм a = 6,0 м;
- Высота фермы на опоре 1,5 м, в середине 2,5 м;
- Кровля — профлист по прогонам;
- Снеговой район — III (по СП 20.13330);
- Расчётная снеговая нагрузка S_g = 1,8 кПа;
- Класс стали поясов и стержней — **С245** по ГОСТ 27772.

## 3. Сбор нагрузок на ферму

Постоянная (вес кровли, прогонов, ферм): g_пост = 0,8 кПа.
Снеговая: g_сн = 1,8 кПа.
Полная погонная: q = (0,8 + 1,8) × 6,0 = 15,6 кН/м.

## 4. Расчётные усилия в стержнях (наиболее нагруженные)

| Стержень | Тип | N, кН | Знак |
|---|---|---|---|
| В-1 (верхний пояс) | сжатие | −340 | сжатый |
| Н-1 (нижний пояс) | растяжение | +330 | растянутый |
| Р-1 (раскос) | сжатие | −180 | сжатый |
| Р-2 (раскос) | растяжение | +95 | растянутый |
| С-1 (стойка) | сжатие | −60 | сжатый |

## 5. Подбор сечений

Принято: нижний пояс — два спаренных уголка 100×100×10 (A = 38,4 см²);
верхний пояс — два спаренных уголка 100×100×10 (A = 38,4 см²);
раскосы — два спаренных уголка 75×75×8 (A = 23 см²);
стойки — два спаренных уголка 50×50×6 (A = 11,6 см²).

R_y = 240 МПа = 24,0 кН/см² (для С245).

## 6. Проверка прочности

Нижний пояс (растяжение): σ = N/A = 330/(38,4 × 0,9) = 9,55 кН/см² < R_y = 24,0 — проходит
с трёхкратным запасом.

Верхний пояс (сжатие): N/A = 340/38,4 = 8,86 кН/см² < R_y — **проходит** (проверка на
устойчивость не выполнялась, считаем что прочности достаточно).

## 7. Сварные швы

Сварка — ручная дуговая, электроды Э42 по ГОСТ 9467-75.

## 8. Состав документации

Раздел содержит: пояснительную записку, статический расчёт, чертежи ОВ (общий вид) фермы.
