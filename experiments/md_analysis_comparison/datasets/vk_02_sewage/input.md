# Раздел ВК. Внутренняя канализация. Жилой дом, корп. 5

## 1. Нормативная база

- **СНиП 2.04.01-85*** «Внутренний водопровод и канализация зданий»;
- ГОСТ 3262-75 «Трубы стальные водогазопроводные».

## 2. Описание системы

Жилой дом 12 этажей, 1 секция, 48 квартир.
Каждая квартира оборудована: ванна, раковина, мойка, унитаз, стиральная машина.

Система внутренней хоз-бытовой канализации — самотёчная, с выпуском в наружную сеть.

## 3. Расчётные расходы

Расход на одного жителя q_тот = **300 л/(сут·чел)** (норма по СНиП 2.04.01-85*).
Число жителей U = 48 × 3 = 144 чел.

Q_сут = 144 × 300 = 43 200 л/сут = 43,2 м³/сут.

Секундный максимальный расход:

q_max,s = 0,2 × √(N × P) + q_0 (по приложению 3 СНиП 2.04.01).

Принимается P = 0,015 (для жилого дома). N = 144 × 5 (приборов на квартиру) = 720.

q_max,s = 0,2 × √(720 × 0,015) + 1,6 = 0,2 × 3,29 + 1,6 = **2,26 л/с**.

## 4. Стояк канализации

Принят диаметр **Ø50 мм** для стояка от санузла квартиры до сборного коллектора.
Это стандартное решение для МКД (по габаритам шахты).

## 5. Уклон выпуска

Уклон выпуска канализации до колодца — i = **0,005** (0,5%) для трубы Ø100 мм.
