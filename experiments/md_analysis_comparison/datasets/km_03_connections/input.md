# Раздел КМ. Узлы крепления стропильной фермы ФС-1 к колоннам К-1

## 1. Нормативная база

- СП 16.13330.2017 «Стальные конструкции» (ред. 2022, изм. 1-5);
- СП 20.13330.2016 «Нагрузки и воздействия»;
- ГОСТ 27772-2015 «Прокат для строительных стальных конструкций»;
- ГОСТ Р ИСО 898-1-2014 «Болты, винты и шпильки. Механические свойства».

## 2. Расчётные усилия в узле

Опорная реакция фермы R = 156 кН (с коэффициентом надёжности γ_f = 1,1).

## 3. Узел У-1: опирание фермы на колонну

Опирание фермы на колонну К-1 через опорное ребро. Соединение — фрикционное на
высокопрочных болтах М20 кл. прочности 10.9 по ГОСТ Р 52644.

Количество болтов: n = 6, расположены в два ряда по 3 шт.

R_bh = 0,7 × 1000 = 700 МПа = 70,0 кН/см² (для болтов М20 кл. 10.9).

N_b = R_bh × A_bn × μ / γ_h × n_f = 70 × 2,45 × 0,42 / 1,02 × 2 = **141 кН**
(на один болт, две поверхности трения; A_bn = 2,45 см² для М20 по ГОСТ).

Несущая способность узла: N = 6 × 141 = 846 кН > R = 156 кН → проходит.

## 4. Узел У-2: крепление верхнего пояса к колонне

Соединение сварное. Заводская сварка, электроды Э50А по ГОСТ Р 51286 (рекомендуется для С355).

Стенка катета шва k_f = 8 мм; длина шва l_w = 280 мм (с двух сторон).

Прочность шва (по СП 16.13330 п. 14.1.7):

N_w = β_f × k_f × l_w × R_wf × γ_wf × γ_c = 0,7 × 0,8 × 28 × 18,0 × 1,0 × 1,0 = **282 кН**

R = 156 кН < N_w = 282 кН → проходит с запасом.
