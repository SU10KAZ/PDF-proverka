# Раздел АР. Теплотехнический расчёт ограждающих конструкций. Корп. 2

## 1. Нормативная база

Расчёт выполнен в соответствии с:
- **СНиП 23-02-2003** «Тепловая защита зданий»;
- ГОСТ 30494-2011 «Здания жилые и общественные»;
- СП 23-101-2004 «Проектирование тепловой защиты зданий».

## 2. Исходные данные

- Климатический район — II В (г. Москва);
- Расчётная температура внутреннего воздуха t_в = +20 °C;
- Расчётная температура наружного воздуха t_н = −28 °C (наиболее холодная пятидневка);
- Влажностный режим помещения — нормальный;
- Зона влажности — нормальная;
- ГСОП = 4943 °C·сут.

## 3. Конструкция наружной стены

Многослойная навесная фасадная система с вентилируемым зазором:
1. Внутренний слой — ж/б 200 мм, λ = 1,92 Вт/(м·°C);
2. Утеплитель минеральная вата, плотность 145 кг/м³, λ = 0,043 Вт/(м·°C), толщина **140 мм**;
3. Воздушный зазор 50 мм (не учитываем);
4. Облицовка керамогранит 12 мм (не учитываем как несущественный термический слой).

**В таблице ниже принята толщина утеплителя 120 мм** (см. п. 4).

## 4. Расчёт сопротивления теплопередаче R_o

| Слой | δ, м | λ, Вт/(м·°C) | R, м²·°C/Вт |
|---|---|---|---|
| Внутренняя поверхность 1/α_в | — | 8,7 | 0,115 |
| Ж/б стена | 0,200 | 1,92 | 0,104 |
| Утеплитель **120 мм** | 0,120 | 0,043 | 2,791 |
| Наружная поверхность 1/α_н | — | 23 | 0,043 |
| **Итого R_o** |  |  | **3,05** |

## 5. Сравнение с требуемым сопротивлением

По СНиП 23-02-2003 (таблица 4) для жилых зданий в Москве R_тр = 3,16 м²·°C/Вт.

Полученное R_o = 3,05 м²·°C/Вт < R_тр = 3,16 м²·°C/Вт — **расчёт выполнен с запасом (так
полагает проектировщик)**, конструкция принимается.

## 6. Состав документации

Раздел включает: пояснительную записку, теплотехнический расчёт. Узлы фасада см. в
отдельной части (выпускается позднее).
