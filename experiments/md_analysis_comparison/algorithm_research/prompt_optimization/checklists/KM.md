# Completeness checklist — КМ (Конструкции металлические)

Tier convention:
- **M** — Mandatory: absence on full_rd = ПРОВЕРИТЬ_ПО_СМЕЖНЫМ; explicit
  contradiction = КРИТИЧЕСКОЕ.
- **R** — Recommended: absence = РЕКОМЕНДАТЕЛЬНОЕ.
- **O** — Optional: do not report absence.

Apply only items the document's `document_type` covers (see completeness
prompt routing rules).

## Mandatory cross-discipline references (if applicable)

- Нагрузки от ОВ/ВК-оборудования на покрытие / фермы (M).
- Опирание перекрытий КЖ на металлические колонны (M).
- Координация с АР по узлам сопряжения (R).

## Anti-pattern (don't flag)

- Указание производителя профилей/электродов само по себе не нарушение.
- Применение Э42/Э50А — стандартные электроды; марка не критическая.
- Расчётный пролёт без явного указания γ_n при наличии всех нагрузок и
  стандартных γ_n=0,95...1,0 не повод для КРИТИЧЕСКОГО.
