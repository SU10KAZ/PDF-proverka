# Completeness checklist — MULTI / TZ vs RD comparison

Для случаев, когда MD содержит сравнение технического задания (ТЗ) и
рабочей документации (РД), checklist фокусируется на полноте отражения
требований ТЗ в РД.

## Sections

| Tier | Item | Norm reference |
|---|---|---|
| M | Каждое требование ТЗ имеет соответствующее решение в РД | ГОСТ Р 21.1101-2013 |
| M | Отклонения от ТЗ обозначены явно (через "Лист изменений" или согласованный protocol) | ГОСТ Р 21.1101-2013 |
| M | Параметры РД количественно совпадают с ТЗ (или есть письменное согласование изменения) | — |
| R | Спецификация оборудования РД соответствует составу ТЗ | ГОСТ 21.110-2013 |

## Anti-pattern

- Каждое расхождение значения параметра — отдельный finding,
  `tz_rd_mismatch_<parameter>`; не дублировать через "ещё одно расхождение
  по этому же оборудованию".
