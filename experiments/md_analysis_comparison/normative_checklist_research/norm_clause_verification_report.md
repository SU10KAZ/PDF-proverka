## EOM-05 — Перечень электроприёмников с P_уст, K_с, P_расч

### Заявленное основание

```
[problem_class=missing_calculation_basis, severity=ЭКСПЛУАТАЦИОННОЕ, applies=full_rd|specification_only]
Перечень всех электроприёмников с указанием P_уст, K_с, P_расч
(СП 256.1325800.2016, п. 6.4).
```

### Фактическое содержимое п. 6.4

```
6.4 В общественных и жилых зданиях разрешается размещать встроенные и
пристроенные трансформаторные подстанции (ТП), в том числе комплектные
трансформаторные подстанции (КТП), при условии соблюдения требований
соответствующих санитарных и противопожарных норм, требований
настоящего свода правил.
```

**Topic mismatch.** П. 6.4 — это про размещение ТП в общественных и
жилых зданиях, не про перечень электроприёмников.

### Где реально лежит требование

Семантический поиск по запросу «перечень электроприёмников с
установленной мощностью, коэффициент спроса, расчётная мощность»
(top-5 по `СП 256`):

- **п. 7.1.5** — расчётная нагрузка от бытовых электроплит, формула P_p.pl = P_пл·η·K_c.pl
- **п. 7.1.6** — расчётная нагрузка вводов
- **п. 7.1.8** — расчётная нагрузка линий питания электродвигателей
- **п. 7.2.1** — коэффициент спроса для рабочего освещения общественных зданий
- **п. 7.2.8** — расчётная нагрузка предприятий общественного питания

Все они в **разделе 7 «Нагрузки»** СП 256.1325800.2016, разделы 7.1 и 7.2.

### Verdict

**Status:** wrong clause.
**Confidence:** high.
**Recommended action:** **Replace basis** в чек-листе на:

```
(СП 256.1325800.2016, раздел 7 «Нагрузки»; п. 7.1 — жилые здания,
п. 7.2 — общественные здания)
```

Удалить устаревшую ссылку «п. 6.4». В metadata оставить
`requires_human_validation=true` до подтверждения подпунктов
инженером-электриком (точные таблицы K_c в разделе 7).

## AR-08 — Расчёт инсоляции жилых помещений

### Заявленное основание

```
[problem_class=missing_mandatory_parameter, severity=ЭКСПЛУАТАЦИОННОЕ, applies=full_rd]
Расчёт инсоляции жилых помещений
(СП 50.13330.2012, СанПиН 1.2.3685-21).
```

### Проблема №1: СП 50.13330.2012 — заменён

Согласно `norms/norms_db.json`:

```
"СП 50.13330.2012": {
  "status": "replaced",
  "current_version": "СП 50.13330.2024 «Тепловая защита зданий»
                      (введён 16.06.2024)",
  "replacement_doc": "СП 50.13330.2024"
}
```

### Проблема №2: СП 50 — это «Тепловая защита», не инсоляция

Семантический поиск «расчёт инсоляции жилых помещений требования»
по СП 50.13330.2024 даёт top-5 результатов про тепловую защиту полов,
энергоэффективность теплоизоляции, воздухообмен — **ничего про
инсоляцию**. СП 50 регулирует тепловую защиту, не инсоляционный режим.

### Где реально лежит требование

- **СанПиН 1.2.3685-21** «Гигиенические нормативы и требования к
  обеспечению безопасности и (или) безвредности для человека факторов
  среды обитания» — раздел III и Таблица 5.34 (инсоляция жилых помещений).
- Также **СП 23-102-2003** «Естественное освещение жилых и общественных
  зданий» (если действует), но это другой документ.
- Историческая ссылка СанПиН 2.2.1/2.1.1.1076-01 — отменена.

(СанПиН family пока не поддерживается локальным `mcp__norms` —
detected_family=null. Точный номер пункта/таблицы нужно подтвердить
через WebSearch или engineer-валидацию.)

### Verdict

**Status:** wrong norm (СП 50 не про инсоляцию) + outdated edition
(.2012 → .2024) + unverified clause number в СанПиН.
**Confidence:** high (по факту wrong-norm); medium (по точному номеру
таблицы в СанПиН).
**Recommended action:** **Replace basis** + **keep shadow-only**:

```
(СанПиН 1.2.3685-21, раздел III; для жилых помещений см. требования к
продолжительности инсоляции)
```

Убрать СП 50 полностью (нерелевантна). Точный номер таблицы /
пункта — `requires_human_validation=true`, **shadow-only** до WebSearch
или engineer-валидации (архитектор + санитарный гигиенист, см.
`final_report.md` §"Подтвердить точные номера пунктов").

### Проверка СанПиН 2.1.4.1074-01

```

```

authoritative проверка невозможна.

Из текстов других норм в vault:

- **СП 60.13330.2020 п. 12.1** «Водоснабжение камер орошения...
  следует предусматривать водой питьевого качества **согласно СанПиН

  ссылочных документах.
- **ГОСТ Р 55295-2012** Приложение [4]: «СанПиН 2.1.4.1074-2001.
  Питьевая вода. Гигиенические требования к качеству воды
  централизованных систем питьевого водоснабжения».

То есть документ **формально цитируется** в действующих СП. Но
фактически Постановление Главного государственного санитарного врача

среды обитания (`1.2.3685-21` пришёл на смену). Статус СанПиН
2.1.4.1074-01 после 2021 года требует **внешнего подтверждения**
(WebSearch + engineer).

### СП 30 / СП 73 — действующие

`СП 30.13330.2020`, `СП 73.13330.2016` — действующие СП по
внутреннему водопроводу и санитарно-техническим работам. Это часть
этого item корректна, но эти СП регулируют **проектирование** и
**производство**, а не саму программу гидравлических испытаний (она —
ПНР-документ).

### Verdict

**Status:** unverified.
**Confidence:** medium (документ цитируется в действующих СП, но
прямого подтверждения актуальности нет).
**Recommended action:** **Keep shadow-only**. Не выводить как
missing finding до подтверждения, что СанПиН 2.1.4.1074-01 либо
действует, либо заменён. Альтернативное основание для самой программы

```
актуальности через WebSearch и/или ВК-инженера)
```

`allow_in_shadow_only=true`. Также, поскольку программа испытаний —

## Дополнительные находки

### СанПиН family не индексируется локально

`mcp__norms` возвращает `unsupported_family` для всех СанПиН-запросов.
Это значит:

- любой чек-лист, ссылающийся на СанПиН, нельзя верифицировать
  автоматически через локальный vault;
- requires_human_validation=true для **всех таких items** оправдан;
- желательно добавить SanPiN индексацию в build_status_index.py /
  расширить `norms/vault/` (отдельный sub-task).
