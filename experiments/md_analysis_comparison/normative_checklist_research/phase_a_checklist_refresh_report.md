## Какие пункты всё ещё требуют human validation

Все 6 items по-прежнему имеют `requires_human_validation=true` /
`allow_in_shadow_only=true` в metadata. Phase A заменил **формулировку
основания**, но **не отменил** требование engineer-валидации, потому
что:

1. **EOM-05** — раздел 7 СП 256 содержит 5+ разных таблиц K_c
   (бытовые плиты, освещение, двигатели, общепит). Инженер-электрик
   должен определить, какие из них уместно цитировать для каждого
   подтипа объекта.
2. **EOM-07** — нужно подтверждение, достаточно ли п. 12.6 или нужна
   параллель с ГОСТ Р 50571.5.52.
3. **KJ-08** — п. 8.1.47/48/49/50 относятся к разным случаям
   продавливания (без поперечной арматуры, с поперечной, со сдвигом
   моментов). Конструктор-ЖБ должен указать применимый для конкретного
   проекта.
4. **KJ-16** — между анкеровкой (10.3.21–10.3.28) и нахлёстом
   (10.3.29–10.3.30) формул много. Нужен инженерный выбор основных
   пунктов для чек-листа.
5. **AR-08** — конкретный номер таблицы инсоляции в СанПиН 1.2.3685-21
   (предположительно 5.34) подтвердить через WebSearch + санитарный
   гигиенист.
6. **VK-20** — формулировка не менялась. Статус СанПиН 2.1.4.1074-01
   на 2026 год (действует / заменён) требует подтверждения
   ВК-инженером.
