## `_blocks.json` — возвращение геометрии

Схема (schema_version=1): `document_id`, `document_name`,
`document_path` (**содержит дисциплину**: «АР / …», «ВК / АТП0»), `generated_at`,
`coordinate_space: "normalized_page_top_left"`, `pages[]`, `blocks[]`.

**pages[]** — ВСЕ страницы PDF (сверено с pdfinfo на 4 доках):
- `page_index` (0-based), `width_px`/`height_px`, `rotation`.
- `rotation` == `/Rotate` из PDF (сверено на всех страницах АР, выборочно ЭО).
- width/height_px — размеры **ПОСЛЕ поворота** (визуальные), рендер ~300 DPI
  с потолком ~100 МП: на больших листах DPI падает (ЭО p10: 293.5; АПТ: 254/207).
  **Масштаб считать как width_px/(mediabox_width_pt/72), НЕ хардкодить 300.**

**blocks[]** — все блоки, включая штампы:
- `block_id` («blk_» + 32hex — ровно как в MD), `ordinal`, `page_index`,
  `page_label` (== page_index+1 всегда), `block_type` (text|image|stamp),
  `shape_type` (rectangle|polygon), `status`/`export_status` (в сэмплах только
  «recognized»), `coords_norm` [x0,y0,x1,y1], `polygon_points`, `crop_url`.
- **coords_norm нормализованы к левому-верхнему углу ВИЗУАЛЬНОЙ (после /Rotate)
  ориентации** — подтверждено дословным совпадением текста региона с MD на
  rotation=0, 90 и 270. Формулы пересчёта visual→unrotated (обе top-left):
  rot=90: u=y_vis, v=1−x_vis; rot=270: u=1−y_vis, v=x_vis.
- `polygon_points` — пары [x,y] в том же пространстве; `coords_norm` полигона =
  его точный bbox. Полигоны только у image-блоков (АР 2, ПС 4, ЭО 33, АПТ 10).
- **stamp-блоки**: `ordinal = null`, `crop_url = null` (у всех 96) — сортировка
  по ordinal и построение URL кропа обязаны фильтровать штампы. Лежат в
  правом-нижнем углу (coords ≈ [0.67–0.89, 0.79–0.93, 0.99, ~1.0]); их
  содержимое = строка **Stamp:** блоков той же страницы.
- `ordinal` сквозной 1..N по документу и **равен номеру «BLOCK #N» в MD**
  (0 расхождений); множество text+image id == множеству blk_-id в MD == HTML.
- Консистентность с MD своей генерации 1:1: crop-токены совпадают полностью
  (даже у АПТ0 генерации 07-10).

## Формат `_results.md` (не менялся с 13.07; грамматика жёсткая)

Скелет (0 отклонений на 316 блоков):
- Шапка ровно из 5 элементов: `# Document: <имя>.pdf`, `Path: <дисц.> / <папка> / <имя>.pdf`,
  `Generated: … UTC`, `**Stamp:** Code|Stage|Object|Organization` (без Sheet/Name),
  `---` (единственный на файл). TOC в MD нет.
- `## Page N` — 1-based, монотонно, число == страницам PDF (в этих сэмплах).
- Блок: `### BLOCK #N [TEXT|IMAGE]: blk_<32hex>` + ровно 3 quoted-строки в
  фиксированном порядке: `> **Created:**`, `> **Crop:** [Crop](https://vibe.cloud-ip.cc/api/crops/<токен 20 симв.>)`,
  `> **Stamp:** Code | Stage | Sheet | Object | Name | Organization | Revisions`
  (все 7 ключей всегда; Revisions всегда пуст).
- [IMAGE]: строка `**[IMAGE]** | Type: X [| Axes: …][| Zone: …][| Level: …]`,
  затем строго **Summary:** → **Description:** (нумер. список) → **Entities:** →
  **Verification:**. Type: План, Схема, Узел, Разрез, Спецификация, Смешанный
  фрагмент, График.
- [TEXT]: сырой markdown; маркера `**[TEXT]**` в теле НЕТ; внутри только
  заголовки ####–###### (### всегда = BLOCK) — сегментация по `^### BLOCK ` и `^## Page `.
- Конца-маркера файла нет (обрыв на содержимом последнего блока).

Грязь в значениях (нормализация обязательна):
- **Stamp парсить по известным ключам** `(Code|Stage|Sheet|…): `, не по двоеточию
  (Object содержит «по адресу: г. Москва», Axes — «Оси:», «Горизонтальные:»).
  Split по ` | ` безопасен. Пустые значения: `Sheet:  |` (двойной пробел),
  хвостовой `Revisions: `.
- **Sheet неуникален и бывает пуст**: ПС «Sheet: 1» на 5 страницах (титул И
  кабельный журнал), ЭО листы 1–5 повторяются в приложении (стр. 50–54),
  АПТ «Sheet: 7» на 3 страницах с разными Name. Ключ листа = страница PDF ✓.
- **Гомоглифы**: АПТ — кириллические «ОО» в коде файла vs «00» у остальных,
  кириллическая «О» на конце Stamp-Code vs цифра «0» в имени, Path даёт третий
  вариант «АТП0/АТП»; в OCR латиница внутри кириллицы («КПCнг», «ГOST»,
  «electroщитовых») и даже CJK («弱电», «с引出 линиями»). Сравнение кодов/марок —
  только через нормализацию гомоглифов.
- Задвоенные маркеры списков `- - `, `1. 1. ` — сотни на документ, схлопывать.
- Юникод-индексы осей (Д12₂) — семантика, не мусор; не фильтровать не-ASCII.
- Created немонотонен (TEXT-проход раньше IMAGE-прохода); порядок блоков =
  позиция в файле == (page_index, ordinal).
- Кавычки: у АР “ ”, у остальных « », бывают висячие ".

## Формат `_results.html`

- Самодостаточная страница: 1 inline `<style>`, 0 script/link/img/svg; nav.toc
  (ссылки #page-N, метка «Sheet N — Название» если штамп распознан).
- `<section class="page" id="page-N" data-page-index="N">` — **0-based**;
  `<h2>Page M</h2>`, TOC и «(page P)» в block-header — **1-based**. Не смешивать.
- Блок: `<article class="block block-text|block-image" id="block-blk_…"
  data-block-id data-block-type>` + block-header («Block #N (page P) | Type | ID»),
  meta-created, block-crop (ссылка), stamp-info; контент text-блоков в обёртке
  div.ocr-html, у image-блоков обёртки НЕТ (селектор .ocr-html их пропустит).
- data-page-index только на section — page блока восстанавливается от предка.
- Координат нет ни в каком виде. Stamp-блоков в HTML нет (как и в MD).
- ⚠️ **«HTML богаче MD» больше не всегда верно**: в генерации 07-15 (АР) из
  ocr-html исчезли colspan/rowspan/br/sup (28/8/29/3 → 0), таблицы разложены
  на плоские td, in-block заголовки стали честными h4–h6 (1:1 с MD). Старые
  генерации (ПС 07-12, ЭО 07-11, АПТ 07-10) — прежний богатый рендер
  (rowspan/colspan/br/sup/math, MD доказуемо искажает шапки таблиц, «;»-склейка,
  «мм²»→«мм2», rowspan-примечания теряют связь). Выбор источника таблиц —
  по факту наличия colspan/… в конкретном файле, не по дате.
- `<math>` содержит сырой LaTeX (не MathML); в MD тот же LaTeX без $-ограничителей.

## Кропы `/api/crops/<token>` (сетевые пробы: 10 шт., 4 дока, все типы)

- Все HTTP 200 **без auth**; content-type application/pdf; одностраничный PDF 1.7;
  размер страницы == области блока. nginx/Caddy,
  `cache-control: public, max-age=31536000, immutable` — скачанное кэшировать вечно.
- Битый токен → **HTTP 403** (не 404) с JSON `{"detail":"Недействительная ссылка на crop"}`.
- АПТ — вектор (шрифты, полный текст-слой, дословно == MD, включая Д-индексы);
  АР/ПС/ЭО — растр 300 DPI (x-ppi=300) без текста. block_type НЕ предсказывает
  наличие текст-слоя — проверять pdffonts/pdftotext по факту.
- Размеры: 128 КБ … 14,8 МБ (полигон АПТ с embedded 600 DPI подложкой);
  медиана ~611 КБ. Оценка кэша: ЭО ≈ 150 МБ/док; АПТ от ~10 МБ до сотен МБ
  из-за аутлаеров. Лимит на размер скачивания обязателен.
- В текст-слое кропа встречаются латинские гомоглифы («Д-RU.PA06» лат. P/A).
