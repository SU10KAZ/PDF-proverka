## Известные грабли формата (по 3 выгрузкам)

- **Координат нет нигде** (`data-bbox` = 0). В старом `ocr.html` их было 653 — портал
  вычистил сознательно. vibe = наша инфраструктура, upstream-фикс возможен.
- **Кропы `/api/crops/<token>` — растр 300 DPI в PDF-обёртке, БЕЗ текст-слоя**
  (`pdftotext` = 0 на 5 пробах от 07-15; обещанная переделка на векторные ещё не выкачена).
  Вектор-слой только в исходном PDF → вектограф вести по исходнику через `## Page N`;
  кроп = картинка для vision. Качаются curl без auth.
- **Crop-токены живут per-generation:** при пере-генерации АР1.2-1 07-15 ВСЕ токены
  сменились → решение «качать при ingest» подтверждено.
- **Страницы без блоков пропускаются** из MD и TOC; в HTML `data-page-index` = стр. PDF − 1.
- **HTML богаче MD:** настоящие rowspan/colspan/br/sup/math; в MD теряются уровни
  заголовков, появляются ложные header'ы таблиц, «;»-склейка ячеек →
  для таблиц и text_evidence первичен HTML.
- **Аномалии парсера:** «Zone: Этаж: 10» (вложенное двоеточие), юникод-индексы в Axes
  (Е₁₉₂), обрезанные таблицы, задвоенные маркеры («1. 1.»), `Created` немонотонен,
  кавычки “” vs «», OCR-регрессии латиницей («АР1.2-1» → «AP1.2-1»).
- `[STAMP]` / `[FAILED]` в образцах не встречались ни разу — только `[IMAGE]` / `[TEXT]`
  (в HTML есть лишь CSS-классы). Фикстур нового формата: 0.
- Для ЭОМ портальные описания однолинеек ненадёжны: ГРЩ описан хорошо, но пофидерных
  данных нет; лист ВРУ-П 1684×5958pt — полная галлюцинация; марки перевраны
  (Муртек→Миртек, ПКЗ ШМК96→ПКЭ ЩМК96, РУНН 10,4кВ→0,4). Визуальный канал/вектор-слой обязателен.
