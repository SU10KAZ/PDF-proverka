# Блоки разных дисциплин — кандидаты для «граф-иерархии»

Реальные блоки-схемы объекта 214 (Alia) с **текстовым слоем PDF** — для ручного разбора
и проектирования профилей извлечения графа (узлы/рёбра/атрибуты) под каждую дисциплину.

Источник: R2 crop_url (где жив) либо рендер из document.pdf (fallback). Все PDF — вектор,
текст выделяется (проверено get_text).

> ⚠️ Это СХЕМЫ (топология), НЕ планы. Планы этажей отсеяны — граф-иерархия строится по схемам.

## СС (3 блоков)
_Профиль `low_voltage_scheme` разделён на три геометрические грамматики. АПС:
43/43 локальных блоков проходят гейт (9628 адресных точек), из них 16 этажных
иерархий `ПО→АЛС→этаж→устройство` и 27 адресных фрагментов без выдуманного этажа;

клеммные связи ожидают трассировку vector paths. Прогон — `СС/run_low_voltage.py`._
