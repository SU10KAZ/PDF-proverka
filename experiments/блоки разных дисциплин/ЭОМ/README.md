# ЭОМ — полный разнообразный корпус

Раздел ЭОМ больше не ограничен шестью однолинейными схемами. Полный реестр объекта ALIA
содержит 1745 графических блоков: 1425 предметных, 113 таблиц/легенд и 207 служебных либо
чужедисциплинарных фрагментов. Из предметной части выбран воспроизводимый корпус из 157
векторных PDF, покрывающий 12 логических профилей и 50 подтипов.

## Итог

- 157/157 блоков проходят профильный гейт;
- 153 являются полными эталонами, 4 ограничены отсутствующим текстовым слоем;
- 147 блоков имеют статус полного описания по своей грамматике;
- 3 блока честно ограничены источником: в PDF есть геометрия, но нет текстового слоя;
- расчётные однолинейные схемы обрабатывает строгий Вектограф;
- остальные 11 профилей обрабатывает `electrical_geometry.py`;
- планы сохраняют оси, помещения, оборудование, цепи и связные CAD-компоненты трасс;
- физические чертежи сохраняют виды, части, размеры, крепёж и опоры;
- неподтверждённое соседство не превращается в электрическое соединение.

Человекочитаемые описания находятся в `eom_out/*.structure.md`. Все названия типов,
уровней доказательности и ограничений в них русские. Машинные идентификаторы остаются
только в JSON и коде.

## Воспроизведение

```bash
python "experiments/блоки разных дисциплин/ЭОМ/build_eom_full_inventory.py"
python "experiments/блоки разных дисциплин/ЭОМ/extract_eom_diverse_corpus.py"
python "experiments/блоки разных дисциплин/ЭОМ/run_eom_diverse_corpus.py"
python "experiments/блоки разных дисциплин/ЭОМ/audit_eom_semantic_coverage.py"
pytest -q tests/test_electrical_geometry.py
```

Артефакты:

- `EOM_ALL_BLOCKS_INVENTORY.json` — классификация всех 1745 image-блоков;
- `EOM_DIVERSE_CORPUS.json` — происхождение и метрики 157 эталонных вырезок;
- `eom_out/summary.json` — итог профильных гейтов;
- `EOM_SEMANTIC_COVERAGE.json/.md` — проверка инженерно значимых подписей;
- `EOM_PROFILES.md` — грамматики всех типов;
- `EOM_GRAPH_AUDIT.md` — границы полноты и доказательности.

Прежние шесть эталонов и `run_vectograf.py` сохранены как узкая регрессия расчётных
однолинеек. Они входят и в новый общий корпус.
