# ЭОМ — эталонный корпус Вектографа

Шесть реальных векторных однолинейных схем объекта 214. Корпус теперь запускается
не вручную, а напрямую через актуальные `build_singleline_graph`,
`evaluate_vectograf_gate` и `render_graph_etalon_markdown`.

Итог: **6/6 PDF строят граф и 6/6 проходят гейт Вектографа**. Нейросеть и OCR не
используются.

`QF узлов / подписей`: Вектограф хранит один узел на уникальную подпись. Если в ПД
две физические позиции имеют одинаковое обозначение, обе позиции считаются, но в
графе схлопываются и явно попадают в `duplicate_qf_labels`/warnings.

## Два поддержанных диалекта ЭОМ

1. Исходный диалект Вектографа:
   `К1.1.1С1 : 522кВт - 0.177 - 0.98 - 92.39кВт - 143.3А`.
2. Диалект ЭО2-ПА, обнаруженный на блоке `4LQJ-LYHX-M3T`: код `2РП4-2`
   вынесен отдельно, а формула записана как
   `3 - 1 - 3 - 0,85 - 5,36 - 180 - 1,89`
   (`Ру–Кс–Рр–cosφ–I–L–ΔU`).

Второй вариант распознаётся только при наличии ближайшего кода вида `2РП…`, поэтому
произвольные строки из семи чисел не становятся ложными фидерами.

## Воспроизведение

Из корня репозитория:

```bash
python "experiments/блоки разных дисциплин/ЭОМ/run_vectograf.py"
```

Результат появляется в `vectograf_out/`:

- `summary.json` — метрики всех шести блоков;
- `<block_id>.graph.md` — логическое Markdown-описание каждого графического блока;
- полный `<block_id>.graph.json` — только с флагом `--include-json`.

Команда завершается ненулевым кодом, если хотя бы один PDF не построился или не прошёл
гейт качества. Регрессия корпуса находится в `tests/test_vectograf_eom_profiles.py`.

## Честные неоднозначности исходных PDF

- `466U` и `7HYD`: подпись `QF2.3` повторена; в `466U` также 52/53 кодов связаны.
- `4LQJ`: повторены `QF4.13` и код `2РП4-14`; 44/45 кодов связаны.
- `4PAG`: повторены `QF1.1` и `QF2.1`; 67/71 кодов связаны.
- Эти случаи не чинятся догадкой: граф получает `needs_review` и точные warnings.

`EOM_etalon_graph.md` — прежний ручной подробный эталон для `7HYD-CUDD-FPU`.
Он сохранён как экспертная контрольная точка; актуальные документы воспроизводимо
генерируются Вектографом.
