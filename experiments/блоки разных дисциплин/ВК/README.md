# ВК — полный эталонный корпус Вектографа

В папке собраны 168 разнообразных графических блоков водоснабжения, канализации,
водоотведения, противопожарного водопровода, АПТ, наружных сетей и насосных установок.
Каждый блок вырезан из исходного PDF по прямоугольнику или полигону с сохранением
текстового, векторного и растрового слоёв.

Корпус покрывает 11 отдельных грамматик:

- планы систем ВК — 12;
- аксонометрии водоснабжения — 3;
- аксонометрии канализации и водоотведения — 7;
- противопожарный водопровод и АПТ — 5;
- принципиальные узлы ВК — 7;
- управление порошковым пожаротушением — 2;
- монтажные узлы ВК — 13;
- водосточные воронки — 5;
- наружные профили, камеры и разрезы — 7;
- чертежи насосного оборудования — 4;
- рабочие характеристики насосов — 2.

Основные файлы:

- `VK_DIVERSE_CORPUS.json` — происхождение и метрики 168 векторных вырезок из 33 исходных комплектов;
- `VK_ALL_BLOCKS_INVENTORY.json` — полный реестр всех 2 089 найденных графических блоков;
- `VK_PROFILES.md` — логика одиннадцати грамматик;
- `VK_GRAPH_AUDIT.md` — честный аудит полноты каждого блока;
- `VK_SEMANTIC_COVERAGE.md/.json` — послойное сопоставление важных инженерных подписей PDF с графами;
- `vk_out/<block_id>.structure.json` — машинный граф;
- `vk_out/<block_id>.structure.md` — полностью русская эталонная разметка;
- `extract_vk_diverse_corpus.py` — воспроизводимое извлечение из исходных PDF;
- `run_vk_diverse_corpus.py` — построение и проверка всех описаний.
- `audit_vk_semantic_coverage.py` — воспроизводимая проверка потерь систем, параметров и оборудования;
- `build_vk_full_inventory.py` — повторная индексация каждого блока без исключений.

Ранние три PDF и пилотный граф противопожарного водопровода сохранены как история
разработки. Актуальным является корпус файлов с префиксом `ВК —`.

Запуск из корня проекта:

```bash
python "experiments/блоки разных дисциплин/ВК/run_vk_diverse_corpus.py"
PYTHONPATH=. pytest -q tests/test_water_geometry.py
```

В 53 блоках полнота текстовых марок подтверждается доступным слоем PDF. В 14 блоках
текстового слоя нет: геометрия сохранена, а сведения из исходного OCR-описания вынесены
в отдельный вторичный слой без координат и не участвуют в доказательстве CAD-связей.
