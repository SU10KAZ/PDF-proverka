# Профили логических схем ALIA

Корпус состоит из 14 разных графических грамматик. Все профили используют только
векторный текст, координаты и CAD paths. Состояние связи всегда показывает, чем она
подтверждена; визуально правдоподобная связь без опоры не становится ребром.

## Пять общих семейств

### Этажная шина

СОТ, СОУЭ, АСКУВТ и связь МГН используют этажные или пространственные полосы.
Оборудование сохраняет контейнеры корпуса и этажа. У СОТ связь камеры с ОСПД
подтверждается совпадением кодов `ВКb.d.* → ОСПДb.d`; у СОУЭ помещения группируются
с подписанной линией `Vn (P, L)` по одному геометрическому ряду.

### Системная магистраль

ВОК, АК и АСУД описывают инфраструктурный backbone. Разные цвета не смешиваются в
одно электрическое ребро. ВОК хранит сегменты `L1…L9`; АК — локальные шкафы и
интеграционные узлы; АСУД — шахты, этажи, переговорные устройства и повторители.

### Портовая связь

Коммутация шкафа трассирует цветные CAD-компоненты между физическими позициями SONAR.
Внешние подключения материализуют колоночную связь «полевое устройство → ХТ → ШАУВ».
Многоаппаратный цветной путь хранится как шина без выдуманных пар.

### Технологический процесс

Функциональная схема хранит поток воздуха, датчики, исполнительные механизмы и
геометрический порядок. Это не этажная иерархия и не клеммная схема.

### Физическое размещение

Компоновка шкафа и организация ниш отвечают на вопрос «что где находится».
Физический порядок и containment не преобразуются в электрические связи.

## Состояния доказательности

- `semantic_confirmed` — связь подтверждена кодами двух устройств;
- `same_row_geometry` — помещение/оконечник привязан к подписанному ряду линии;
- `nearest_same_building_geometry` — соседние уровни иерархии связаны по близости внутри корпуса;
- `blue_path_component` / `colored_path_confirmed` — оба узла касаются одной CAD-компоненты;
- `multi_device_bus` — CAD-компонента задевает более двух аппаратов и не разбивается на пары;
- `physical_layout` / `physical_containment` — только размещение;
- `x_order_geometry` / `column_alignment` — геометрический порядок, не электрическое подтверждение.

## Воспроизведение

```bash
python "experiments/блоки разных дисциплин/СС/extract_alia_scheme_corpus.py"
python "experiments/блоки разных дисциплин/СС/run_alia_scheme_corpus.py"
PYTHONPATH=. pytest -q tests/test_alia_scheme_geometry.py
```

JSON и Markdown каждого блока находятся в `alia_scheme_out/`; общая сводка —
`alia_scheme_out/summary.json`. В сводке 14/14 профилей имеют статус `complete`. Реализация —
`backend/app/pipeline/stages/block_grounding/alia_scheme_geometry.py`.
