# ОВ — эталонный корпус Вектографа

Здесь собраны 154 разнообразных графических блока отопления и вентиляции из 21 исходного комплекта. Каждый блок
вырезан из исходного PDF по прямоугольнику или реальному полигону: текстовый и CAD-слои
сохранены, PNG не используется как источник структуры.

Корпус покрывает девять грамматик:

- планы ОВ — 6;
- аксонометрии отопления — 7;
- аксонометрии вентиляции и дымоудаления — 5;
- принципиальные гидравлические схемы — 3;
- монтажные узлы — 7;
- разрезы — 3;
- чертежи оборудования — 3;
- рабочие характеристики — 2;
- площадочная схема источника тепла — 1.

Основные файлы:

- `HVAC_DIVERSE_CORPUS.json` — происхождение, тип и метрики всех вырезок;
- `HVAC_PROFILES.md` — логическая структура девяти грамматик;
- `HVAC_GRAPH_AUDIT.md` — подробный аудит исходного базового набора из 37 блоков;
- `HVAC_ALL_BLOCKS_INVENTORY.json` — вычисляемый реестр вариантов;
- `HVAC_SEMANTIC_COVERAGE.json` — проверка инженерных фактов всех 154 блоков;
- `hvac_out/<block_id>.structure.json` — машиночитаемый граф;
- `hvac_out/<block_id>.structure.md` — полностью русское человекочитаемое описание в стиле Вектографа;
- `extract_hvac_diverse_corpus.py` — воспроизводимое извлечение из исходных PDF;
- `run_hvac_diverse_corpus.py` — построение описаний и строгая проверка.

Запуск из корня проекта:

```bash
python "experiments/блоки разных дисциплин/ОВ/run_hvac_diverse_corpus.py"
PYTHONPATH=. pytest -q tests/test_hvac_geometry.py
```

Шесть файлов с цифровым префиксом оставлены как ранняя выборка аксонометрий. Новый корпус
с префиксом `OV —` шире и является актуальным эталоном.
