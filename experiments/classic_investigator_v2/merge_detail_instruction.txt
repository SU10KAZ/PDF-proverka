Дополнительный экспериментальный контракт сохранения содержания при объединении.

Для каждого исходного кандидата сначала различи самостоятельные проверяемые тезисы,
адресные примеры, подтверждающие числа и ограничения доказательства. Сохраняй их
связь с конкретным объектом и документом. Совпадение темы не делает разные примеры
дублями. Общий итог не заменяет отдельные количества, массы и сравнения по объектам.

При объединении в одну итоговую строку включи в description отдельное предложение
для каждого различающегося объекта: его обозначение, лист, сопоставленные значения,
единицы и существенные условия. Сохрани проверяемую разбивку расчёта, если именно
она объясняет расхождение. Дублирующееся доказательство можно изложить один раз;
различающиеся значения или адресные примеры нельзя заменить словами «и другие».
Если описание становится неудобным, раздели разные объекты на самостоятельные
строки с теми же корректными source_finding_ids вместо удаления деталей.

Условность должна согласованно сохраняться в problem, description, solution и risk.
Разница в документах сама по себе не доказывает физическую недостачу, отказ или
неправильную комплектацию. Отсутствие источника у аудитора не доказывает отсутствие
решения в проекте. Непроверенные размерные базы и идентичность изделий должны
оставаться явно непроверенными. Не вводи универсальных допусков из частного случая.

Не восстанавливай технически опровергнутый тезис ради полноты. Если исходники
обосновывают уточнение или снятие, сохрани обоснованную границу вывода. Добавленный
факт допустим только при наличии опоры в переданном исходном материале.

Перед выдачей сопоставь все исходные кандидаты со всеми итоговыми строками:
проверь сохранность адресных примеров, численных сопоставлений, условий и
контрдоказательств во всех четырёх человекочитаемых полях. Связь по ID не заменяет
эту проверку. В человекочитаемом тексте используй проектные обозначения и листы,
а внутренние ID сохраняй только в структурированных полях. Схема ответа прежняя.
