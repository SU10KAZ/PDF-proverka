**`VECTOR_03_OBJECT_LAYER_REPORT.md`** — главный отчёт. Часть 0 — три вещи, которые нужно

## Вердикт одной строкой

**A — generic object layer достаточен, дисциплинарные профили не понадобились нигде.** Но его
роль переопределена: вердикт выносит **непарная краска после регистрации**, а слой объектов
даёт **адрес и имя** события. Попытка ключевать сравнение объектами измеримо хуже.

## Что нужно знать сразу

- **Пар П↔РД в корпусе нет** (точность поля `stamp_data.stage` на «П» = 0,133). Все выводы —
  кросс-ревизионные. §21 на этих данных не проверяем.
- **Основание чинилось дважды** по итогам состязательной проверки: гейт путей выбрасывал 45 %
  геометрии, детектор окружностей ошибался в 82,4 % случаев.
- **Метки почти не помогают**: +0,07 п.п.; идентичность несёт положение в общем кадре.
- **Ноль ложных графических изменений** на text-only (700 инстансов) и table-only (104).
- **Главный источник ложных срабатываний — граница кропа**, а не чертёж (36,5 % пар).

## Метод

Числа помечены **[REAL]** (реальные пары) и **[CF]** (контролируемый контрфакт на реальном
блоке) и нигде не смешиваются. Контрфакты нужны потому, что на 29 размеченных парах нельзя
измерить recall и порог чувствительности, а часть классов корпус не даёт вовсе. Контрфакты
систематически легче реальности — там, где вывод опирается только на них, это помечено.
