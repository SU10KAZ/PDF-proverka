### Фактический upstream contract (найден в репозитории, использовать ЕГО)

Источник истины — `result.json` версии документа:

```

```

Схема:

```jsonc
{
  "coordinate_space": "normalized_page_top_left" | null,   // null у legacy-формата
  "source": "blocks_json_v1" | null,
  "pages": [
    {
      "page_number": 5,        // 1-based
      "width": 2482,           // ПИКСЕЛЬНЫЕ размеры страницы в системе result.json
      "height": 3510,
      "rotation": 0 | 90 | 270 | null,
      "blocks": [
        {
          "id": "blk_e794e808...",           // == block_id
          "page_index": "4",                  // 0-based, строкой
          "coords_px": [231, 3182, 2413, 3419],   // [x1,y1,x2,y2] в px-системе result.json
          "coords_norm": [0.093, 0.906, 0.972, 0.974],
          "block_type": "image" | "text",     // ГРАФИЧЕСКИЙ БЛОК == "image"
```

Кропы (PNG) и их индекс:
`.../versions/<VER>/03_analysis/latest/blocks_stage02_100/index.json`

`ocr_label`, `ocr_text_len`, `source`.

### Каноническое преобразование coords_px → PDF (как это делает production)

`backend/app/pipeline/stages/crop_blocks/blocks.py::crop_from_pdf` (строки ~684–720):

```python
page = doc[page_num - 1]                     # page_num 1-based
scale_x = page.rect.width  / page_width      # page_width/height — ПИКСЕЛИ из result.json
scale_y = page.rect.height / page_height
clip = fitz.Rect(x1*scale_x, y1*scale_y, x2*scale_x, y2*scale_y)
pix = page.get_pixmap(clip=clip, ...)        # ЭТО и есть картинка, которую видел человек
```

Тот же путь — `backend/app/services/common/block_pdf_source.py` (восстановление кропа).

> **ВНИМАНИЕ (главная ловушка, подтверждена в v0.2, OBJ‑1).**
> `page.rect` — это **повёрнутый** прямоугольник (учитывает `/Rotate`), и `get_pixmap(clip=…)`
> работает в повёрнутой системе. А `page.get_drawings()` и `page.get_text()` возвращают
> **неповёрнутые** координаты. Если взять `clip`, посчитанный формулой выше, и подать его в
> `get_drawings()` — на страницах с `/Rotate 90|270` вы прочитаете **другую часть листа**,
> чем показывает PNG. В v0.2 это дало пересечение 0 из 217 094 точек на одной паре.
> Правильный путь: `page.derotation_matrix` для входа в собственную систему страницы и
> `page.rotation_matrix` — обратно. Каждый зонд обязан это проверить у себя (см. §26).

В корпусе: 5 952 image-блока на страницах rot=0, **738 на rot=270**, **94 на rot=90**
(в выборке 250 файлов), 14 568 — rotation отсутствует в result.json (legacy → читать из PDF).

## 5. ПРАВИЛА РАБОТЫ ЗОНДА

1. **Измерять, а не рассуждать.** Каждое утверждение — число + файл-артефакт в
   `artifacts/`. Утверждение без числа не пишется вообще.
2. **Пытаться опровергнуть себя.** Для каждого утверждения указать, каким измерением
   оно было бы опровергнуто.
3. **Никаких синтетических блоков.** Только реальные `block_type == "image"` из
   `result.json`. Если для контроля нужна синтетика — помечать явно как контроль.
4. **Проверка основания перед выводами (§26 брифа).** До любых утверждений об object layer
   зонд обязан показать: система координат верна, `/Rotate` учтён, невидимая краска
   снята, нормировка изотропна, bbox соответствует подготовленному блоку. Для этого
   существует общий модуль — использовать его, а не писать свой (см. §6).
5. **Формат отчёта.** `artifacts/<префикс>_FINDINGS.md`, начинается таблицей:
   `# | утверждение | измерение (число / файл) | уверенность | чем опровергается`.
   В конце — раздел `## Reproduction` с точными командами и `## Gaps / not measured`.
6. Не подключать ничего к production. Не менять файлы вне каталога трека.
7. Русский язык в отчётах допустим и предпочтителен для выводов; код и имена полей — англ.

## 6. ОБЩИЙ МОДУЛЬ ОСНОВАНИЯ

`probes/v03_foundation.py` — единственная разрешённая точка входа для чтения блока:

- `iter_prepared_blocks(result_json)` → подготовленные графические блоки контракта;
- `block_frame(pdf, page_index, coords_px, page_px_w, page_px_h)` → корректный
  `clip` **в собственной (неповёрнутой) системе страницы** + матрицы туда/обратно;
- `extract_block(...)` → сегменты (inked), текстовые строки, растровые вставки, флаги качества;
- `render_block(...)` → PNG ровно того региона, что и production-кроп.

Если модуль ещё не создан — его создаёт зонд `fnd`, остальные ждут и используют.
Дублировать извлечение запрещено: расхождение реализаций уже один раз обесценило бенчмарк.
