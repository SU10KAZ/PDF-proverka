## R-FINAL — что включить в контракт v0.3

| тип | вердикт | решающее измерение |
|---|---|---|
| **CONNECTED_TO** | включить | ложных 0/25 глазом; устойчивость `cond` 0.993 [CF] / 0.995 [REAL] |
| **ADJACENT** | включить (исключив вложенные пары, с капом k ближайших) | адрес 0.716 и прирост сопоставления +0.212 — лучшие из девяти |
| **LABEL_ANCHOR** | включить только на блоках класса «чертёж» | ложных 0.286 на чертежах против 0.667 на штампах |
| **ALIGNED** | только признак сопоставления, кап зазора ≤10·S | +0.189 к top-1, но 16.1 % рёбер длиннее 10·S |
| **REPEATED_WITH** | атрибут объекта, не ребро | адрес 0.000 по построению; 71.4 % рёбер длиннее 10·S |

| **CONTAINS** | выбросить | точный дубль INSIDE, удваивает граф без нового бита |
| **LEADER_TO** | выбросить в этом виде | ложных 0.667, на чертежах 0.60; смешивает выноску, размерную цепочку и линейку таблицы |
