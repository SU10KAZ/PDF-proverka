`probes/v03_foundation.py`. Единица — реальный блок `block_type=="image"` из
`result.json`. Синтетических bbox нет ни одного.

8 796 блоков (16.9 %) прочитать нечем: PDF отсутствует.

## Что это значит для object layer (без домыслов, только следствия чисел)

1. Треть входа — штампы (CNS‑1). Если object layer будет обрабатывать их наравне
   с чертежами, треть бюджета уйдёт на разлинованные таблички, которые дешевле
   читать текстом. Штамп надёжно отделяется бесплатно: `category_code`.
2. Настоящих «слепых» блоков (Vision безальтернативно) всего 3.0 % (CNS‑5), то есть
   вектор-путь применим к 90.9 % блоков (93.1 % без штампов). Ограничение — не растр,
   а **отсутствие подписи**: 29.2 % блоков не дают ни одной марки рядом с геометрией
   (CNS‑7). §6 брифа («объекты без label») — это не редкий случай, а каждый третий блок.
3. 9.2 % блоков — точные дубликаты (CNS‑8). Кэш по `geom_sha` снимает эту работу
   целиком и заодно даёт бесплатный тест на стабильность: дубликат обязан получить
   идентичный набор объектов.
4. Тяжёлый хвост по сегментам (CNS‑10) означает, что стоимость object layer
   определяется не медианой (1.8 тыс. сегментов), а p99 (226 тыс.): 1.16 % блоков
   тяжелее 200 000 сегментов и вынесены из «пригодных» отдельным ярлыком.

## Самоопровержения (что мы проверяли против себя)

- Классы стратифицированы по *предсказанию* в наборе T специально ради поиска
  ложных срабатываний — и они нашлись: правило «штамп по геометрии» (0/4) и
  «текст кривыми» (1/4) были удалены/исправлены, см. `cns_taxonomy_rules.md`.
- Доля классов пересчитана «по документам», а не «по блокам» — расхождение ≤1.7 п.п.
- Дубликаты проверены рендером трёх пар — совпали визуально.
- Строгая и мягкая меры «нет обозначения» разведены (29.2 % против 11.5 %) вместо
  выбора удобной.
- Число F5 «text_in_curves 1.6 %» опровергнуто прямым страничным измерением (CNS‑4).

## Gaps / not measured

- **16.9 % блоков (8 796) не измерены вообще** — у их версий нет `document.pdf`.
  Все доли выше относятся к читаемым 43 261.
- Класс присваивается блоку целиком; внутриблочной сегментации («тут таблица, тут план»)
  не делалось. Листы-целиком (p90 = 65 % площади листа) получают один ярлык.
- «Обозначение рядом с геометрией» = центр текстовой строки в пределах 2·S от середины
  сегмента (S — характерный размер шрифта блока). Это грубая близость, а не выноска;
  зонд `vvb`/`obj` из v0.2 показывал, что настоящий якорь — выноска.
- Дубликаты ищутся точным хешем геометрии. «Почти дубликаты» (тот же узел, пересобранный
  экспортом) не ловятся: OBJ‑11 (v0.2) уже показал, что точный хеш мотива между версиями
  не переносится, поэтому число 9.2 % — нижняя граница.
- `page_text_lines ≤ 5` — порог, откалиброванный на 4 просмотренных блоках; при пороге 0
  класс `curved_text` = 34 блока, при 10 — 80. Разброс класса 0.08–0.18 % ничего в выводах
  не меняет, но сам порог слабый.
- Дисциплины GP (118 блоков), POS (64), TX (449), PT (426) представлены слабо — их доли
  шумные.
- Стоимость (токены/время) object layer не измерялась — это не задача `cns`.
