# `ctr` — МИНИМАЛЬНЫЙ контракт GraphicBlockDescription v0.3

Зонд `ctr`, трек VECTOR 0.3 (Opus). Блоки читались **только** через
`probes/v03_foundation.py`, объекты — только через `probes/v03_objects.py`, семейства —
через `probes/fam_family.py`. Собственного извлечения нет.

**Правило включения поля (жёсткое):** поле входит в контракт, только если названо
измерение трека, которое ломается без него. Для каждого поля измерение указано в таблице
контракта и, где это было можно посчитать на реальных блоках, — проверено абляцией
(`ctr_ablation_ex.json`, `ctr_ablation_pair.json`).

Числа из контролируемых подмен помечены **[CF]**, из реальных пар — **[REAL]**; в одном
утверждении не смешиваются. **Пар П↔РД в корпусе нет** (зонд `pd`: 2 настоящих П-документа,
у обоих нет ни одного `document.pdf`; 124 разобранных кандидата → 0 подтверждённых пар).
Поэтому секция `pair_context` проверена на **30 кросс-ревизионных парах** бенчмарка `mine`
(из 33: 3 пропущены по плотности), а на кросс-стадийных данных — **не на чем проверить**,
своих попыток сверх тех 124, что сделал `pd`, зонд не делал (0).

## Gaps / not measured

1. **П↔РД: не на чем проверить.** Пар нет (зонд `pd`, 124 разобранных кандидата → 0).
   Секция `pair_context` проверена только на кросс‑ревизионной оси (30 пар); попыток найти
   кросс‑стадийные пары в этом зонде — **0** сверх сделанных `pd`.
2. **Контракт не проверен «сквозным» прогоном компаратора.** Я показал, что каждое поле
   нужно (абляция) и сколько стоит (байты/токены), но НЕ прогонял компаратор `loc`/`mov`
   поверх payload вместо живых извлечений: сериализация→десериализация→сравнение не
   измерена ни разу. Это следующий обязательный шаг: без него утверждение «payload
   достаточен» остаётся выводом из абляций, а не измерением.
3. **`transform` и `comparable_share` в `pair_context` объявлены, но заполняются нулями**
   в моей реализации: их значения берутся из `mov`, повторно я их не считал.
4. **Дефект дескриптора едет в контракт.** `loc` L15: дескриптор не инвариантен к переносу
   (45 % конгруэнтных пар дают ненулевое расстояние, 7.25 % > 0.30, максимум 2.00). Контракт
   везёт `desc` как есть; починка сетки занятости — работа зонда `grp`, не моя.
5. **`cycle`/`dashed` выброшены по числам «с обеих сторон»** (`fam` F8), а не по чистому
   опровержению. Если появится измерение, где гейт на `cycle` выигрывает, поля вернутся.
6. **Корпусная доля «буквы полилиниями» (CTR‑15) не измерена** — есть один пример.
   Нужна перепись по признаку «0 текстовых строк, 0 кривых, много коротких сегментов».
7. **Классы блоков берутся из переписи `cns`** (точность правил 94.9 % на holdout), а не
   из независимого источника: ошибка классификации переносится прямо в `route`.
8. **Сравнение с v0.1 (CTR‑1) — на разных выборках** (20 синтетических bbox против 60
   реальных блоков); честно только как порядок величины.
9. **`polygon_pt` меряет чужую краску, но контракт не предписывает её вычитать** — это
   решение потребителя; цена вычитания (потеря настоящих изменений у границы полигона)
   не измерена.
