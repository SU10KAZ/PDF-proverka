# Проверочные скрипты корпуса ЭМ2 для «Сравнения версий»

Воспроизводят факты из `docs/version_comparison_plan.md` (§1.2, §1.3, §15). Перечень скриптов — в §16 плана.

Это инструмент проверки, а не код раздела. Правила:

- скрипты только читают PDF;
- правки (удаление аннотаций) делаются в копии в памяти, она не сохраняется;
- имена файлов корпуса зашиты: `133_23-ГК-ЭМ2 (0…11).pdf`.

## Получить корпус

Архив `experiments/EM2_наложения_и_полный_текст.rar` лежит вне git (236 МБ, RAR5). Системный `7z` RAR5 не распаковывает, поэтому используйте `extract_rar5.py` (через libarchive):

```bash
mkdir -p /tmp/em2 && python3 -I extract_rar5.py "../EM2_наложения_и_полный_текст.rar" /tmp/em2
```

PDF окажутся в `/tmp/em2/EM2_наложения_и_полный_текст/ВЕРСИИ ПРОЕКТОВ/`.

## Запуск

```bash
./run_all.sh "/tmp/em2/EM2_наложения_и_полный_текст/ВЕРСИИ ПРОЕКТОВ" ../EM2_реестр_сравнения.xlsx
```

Отдельный скрипт: `python3 -I <скрипт>.py <папка PDF>`. Исключения:

- `profile_pdfs.py` — вторым аргументом путь к выходному JSON;
- `xlsx_probe.py` — принимает путь к xlsx.
