# Track B — независимый архитектурный аудит VectorBlockDescription (Claude Opus 5)

Исследование. Ничего из этого каталога не подключено к production и не должно быть подключено
в текущем виде.

База: коммит `1619fc3f` (Track A, `experiments/stage_comparison_vector_blocks/`).
Отчёт Codex-трека (`experiments/stage_comparison_vector_blocks_v02_codex/`) намеренно **не
открывался** — нужен независимый второй взгляд.

## С чего начинать

**`OPUS_VECTOR_ARCHITECTURE_REPORT.md`** — главный отчёт. Часть I отвечает на восемь вопросов
коротко, часть II даёт вердикт, дальше идут доказательства.

## Зонды

Каждый зонд — отдельный агент с заданием измерять, а не рассуждать. У каждого свой префикс,
свои скрипты в `probes/` и свой `artifacts/<префикс>_FINDINGS.md`, начинающийся таблицей
«утверждение — измерение — уверенность — чем опровергается».

| Префикс | Тема |
|---|---|
| `signoise` | сигнал против шума: стоимость каждого поля, абляция, избыточность, устойчивость |
| `falsify` | прямая попытка опровергнуть главную гипотезу на реальных блоках |
| `obj` | группировка примитивов в графические объекты без знания дисциплины |
| `relgraph` | граф отношений против списка сегментов |
| `txgeo` | типы отношений «текст ↔ геометрия» |
| `dim` | размеры: детектор, привязка значения к измеряемой геометрии, самопроверка масштабом |
| `hatchnoise` | отделение инженерной геометрии от штриховки и фона |
| `tcf` | доверие к топологии: допуски, капы, X-пересечения, кривые, вложенность |
| `tbl` | реконструкция таблиц как generic-примитива |
| `ptn` | подпись повторяющегося мотива: что отличает 24 символа от 24 элементов штриховки |
| `fmc` | новый сбалансированный корпус режимов отказа (21 пара, 9 дисциплин) |
| `hybrid` | разделение Vector/Vision и бюджет AI-payload |
| `vv*` | Vision-верификация самого описания до сравнения |

Каждый `*_FINDINGS.md` дополнительно проверялся отдельным агентом-оппонентом; результаты — в
`artifacts/*_VERIFY.md`. Опровергнутые и ослабленные утверждения перечислены в части VII отчёта.

## Воспроизведение

Все команды — из корня репозитория. Точные строки запуска указаны в разделе «Reproduction»
каждого `*_FINDINGS.md`. Собственные зонды оркестратора:

```bash
python -m experiments.stage_comparison_vector_architecture_opus.probes.p00_glyph_identity   # O8
python -m experiments.stage_comparison_vector_architecture_opus.probes.p00b_alignment       # O9
python -m experiments.stage_comparison_vector_architecture_opus.probes.p00c_cap_bias        # O11
python -m experiments.stage_comparison_vector_architecture_opus.poc.objects_v02 --pair ss_scheme_text_changed
```

`poc/objects_v02.py` — демонстрация **формы контракта** v0.2, а не рабочий детектор: на
СС-схеме он пересегментирует (101 кандидат-символ вместо примерно 30). Количественные
утверждения о качестве группировки взяты из зондов `obj` и `ptn`, которые мерили это специально.

Требуется PyMuPDF 1.27.2.2 (`fitz`) и `fontTools` (для канонизации глифов).
