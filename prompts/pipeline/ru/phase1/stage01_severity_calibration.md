# Stage 01 — Severity Calibration

Worked-decisions: ситуация → правильная категория → `severity_reasoning` (≤ 120 chars) → counter-example (как неправильно классифицируют LLM).

Возможные категории: `КРИТИЧЕСКОЕ` / `ЭКОНОМИЧЕСКОЕ` / `ЭКСПЛУАТАЦИОННОЕ` / `РЕКОМЕНДАТЕЛЬНОЕ` / `ПРОВЕРИТЬ_ПО_СМЕЖНЫМ`.

---

## Раздел A — КРИТИЧЕСКОЕ (6 эталонных примеров)

### A.1 — EOM — кабель недостаточного сечения

- **Ситуация:** Iдоп кабеля АВВГ 4×95 (220 А) меньше расчётного тока 302 А.
- **Категория:** `КРИТИЧЕСКОЕ`.
- **severity_reasoning:** `"Iдоп 220 А < Iрасч 302 А — тепловой пробой, пожар во ВРУ"` (78 chars)
- **Counter-example (WRONG):** `ЭКСПЛУАТАЦИОННОЕ` — «деградирует со временем». NO: кабель сразу перегружен, не «деградирует».

### A.2 — ОВ — расход вытяжки от газовой кухни занижен

- **Ситуация:** Кухня с газовой плитой, расход 60 м³/ч (норма ≥ 90 м³/ч).
- **Категория:** `КРИТИЧЕСКОЕ`.
- **severity_reasoning:** `"60 < 90 м³/ч — накопление продуктов сгорания, риск отравления и взрыва"` (75 chars)
- **Counter-example (WRONG):** `ЭКСПЛУАТАЦИОННОЕ`. NO: газ + недовент = немедленная опасность жизни.

### A.3 — АР — лестничная клетка Л1 в 19-этажке

- **Ситуация:** H=52,4 м, применена Л1 (требуется Н1 при H>28 м).
- **Категория:** `КРИТИЧЕСКОЕ`.
- **severity_reasoning:** `"Л1 при H=52,4 м запрещена СП 1.13130 п.4.4.16 — гибель при эвакуации"` (74 chars)
- **Counter-example (WRONG):** `ПРОВЕРИТЬ_ПО_СМЕЖНЫМ` — «уточнить по ОВ подпор воздуха». NO: тип Л1 сам по себе запрещён, без смежных не нужно.

### A.4 — КЖ — класс бетона ниже минимального для среды

- **Ситуация:** Несущие стены B15, условия XC3 (мин. B25 по СП 28.13330).
- **Категория:** `КРИТИЧЕСКОЕ`.
- **severity_reasoning:** `"B15 < min B25 для XC3 — коррозия арматуры через 10–15 лет, потеря несущей"` (78 chars)
- **Counter-example (WRONG):** `ЭКСПЛУАТАЦИОННОЕ`. NO: это нарушение СП, не «деградация».

### A.5 — ВК — диаметр стояка для унитаза занижен

- **Ситуация:** Канализационный стояк Ø50 с подключением унитаза (требуется Ø100).
- **Категория:** `КРИТИЧЕСКОЕ`.
- **severity_reasoning:** `"Ø50 < min Ø100 для унитаза — забой стояка, разлив сточных вод в квартиры"` (72 chars)
- **Counter-example (WRONG):** `ЭКСПЛУАТАЦИОННОЕ`. NO: дом непригоден к сдаче, СП 30.13330 прямой запрет.

### A.6 — Cross-discipline — расчётная нагрузка ЭОМ vs ОВ

- **Ситуация:** В ЭОМ заложено 12,0 кВт на ИТП, ОВ требует 18,5 кВт. Автомат ввода 32 А не пропустит.
- **Категория:** `КРИТИЧЕСКОЕ`.
- **severity_reasoning:** `"ЭОМ 12 кВт vs ОВ 18,5 кВт — ИТП не запустится, нет тепла зимой"` (66 chars)
- **Counter-example (WRONG):** `ПРОВЕРИТЬ_ПО_СМЕЖНЫМ`. NO: расхождение видно прямо в документе, ничего «проверять» — это уже дефект.
- **cross_discipline_with:** `["EOM", "OV"]`

## Раздел B — ЭКОНОМИЧЕСКОЕ (3 примера)

### B.1 — Спецификация vs текст: разная марка кабеля

- **Ситуация:** В ПЗ — ВВГнг(А)-FRLS 5×10, в спецификации — ВВГнг(А) 5×10 (на 15% дешевле, без огнестойкости).
- **Категория:** `ЭКОНОМИЧЕСКОЕ` (если разница в цене существенна и марка из ПЗ правильная) ИЛИ `КРИТИЧЕСКОЕ` (если FRLS — обязательное требование).
- **severity_reasoning:** `"Спецификация без FRLS — пересортица на 15% или нарушение огнестойкости"` (72 chars)

### B.2 — Расхождение объёмов: ВОР vs план

- **Ситуация:** В ВОР заявлено 1200 м² стяжки, на планах — 1450 м².
- **Категория:** `ЭКОНОМИЧЕСКОЕ`.
- **severity_reasoning:** `"Расхождение объёмов 1200 vs 1450 м² — недоплата 17% по стяжке"` (61 chars)

### B.3 — Завышение класса огнезащиты — лишние деньги

- **Ситуация:** Для несущих колонн заявлен R150, по нормам достаточно R90.
- **Категория:** `ЭКОНОМИЧЕСКОЕ`.
- **severity_reasoning:** `"R150 vs нормативный R90 — переплата за огнезащиту 40–60%"` (54 chars)

## Раздел C — ЭКСПЛУАТАЦИОННОЕ (3 примера)

### C.1 — Отсутствует кабельный журнал (`full_rd` only)

- **Ситуация:** В составе ЭОМ нет кабельного журнала, есть однолинейная.
- **Категория:** `ЭКСПЛУАТАЦИОННОЕ`.
- **severity_reasoning:** `"Без КЖ невозможно эксплуатировать сети, обходимся при стройке"` (60 chars)
- **document_type guard:** только при `document_type = full_rd`. На `audit_comparison` — DO NOT REPORT.

### C.2 — Низкая скорость воздуха в канале — риск опрокидывания тяги

- **Ситуация:** Скорость в кухонном канале 0,55 м/с (норма ≥ 1,0).
- **Категория:** `ЭКСПЛУАТАЦИОННОЕ`.
- **severity_reasoning:** `"Скорость 0,55 м/с — опрокидывание тяги в межсезонье, обратная тяга"` (66 chars)

### C.3 — D-кривая предпочтительнее C для прямого пуска АД

- **Ситуация:** На ввод ЩВ-ОВ применена C-кривая. C допустима, но D снимает риски ложных срабатываний.
- **Категория:** `ЭКСПЛУАТАЦИОННОЕ` + `is_beyond_gt_useful: true`.
- **severity_reasoning:** `"C-кривая допустима, но D даёт меньше ложных при пуске АД с Iпуск/Iном=6,5"` (76 chars)

## Раздел D — РЕКОМЕНДАТЕЛЬНОЕ (4 «должно было быть РЕКОМЕНДАТЕЛЬНЫМ, а LLM пишет КРИТИЧЕСКОЕ» counter-examples)

### D.1 — Цвет профиля окон не зафиксирован

- **Ситуация:** «Цвет RAL подбирается в производстве».
- **Категория:** `РЕКОМЕНДАТЕЛЬНОЕ`.
- **severity_reasoning:** `"Уточнение по наименованию, не блокирует стройку"` (47 chars)
- **WRONG (LLM-вариант):** `КРИТИЧЕСКОЕ` — «не соответствует требованиям к РД». NO: это не unbuildable, это косметика.

### D.2 — Ссылка на устаревший ГОСТ без последствий для проекта

- **Ситуация:** Ссылка на ГОСТ 23166-99, заменён на ГОСТ 23166-2021. Технические требования по сути совпадают.
- **Категория:** `РЕКОМЕНДАТЕЛЬНОЕ`.
- **severity_reasoning:** `"Устаревшая ссылка, актуальная редакция формально другая, по сути ОК"` (66 chars)
- **WRONG (LLM-вариант):** `КРИТИЧЕСКОЕ` — «нормативная база устарела». NO: устарела ссылка, не суть. КРИТИЧЕСКОЕ ставится, только если в новой редакции требования действительно ужесточились и проект им не соответствует.

### D.3 — Климатический район «II В» — обозначение из СНиП 23-01-99

- **Ситуация:** Применено старое обозначение климатического района.
- **Категория:** `РЕКОМЕНДАТЕЛЬНОЕ`.
- **severity_reasoning:** `"Старое обозначение СНиП 23-01-99, расчёт от этого не меняется"` (58 chars)
- **WRONG (LLM-вариант):** `КРИТИЧЕСКОЕ` — «применена отменённая норма». NO: ссылка устарела, но проект не нарушен.

### D.4 — Нестандартное обозначение «EI 30 dym»

- **Ситуация:** Обозначение типа двери «EI 30 dym» вместо стандартного «EIS 30».
- **Категория:** `РЕКОМЕНДАТЕЛЬНОЕ`.
- **severity_reasoning:** `"Нестандартное обозначение, дверь подобрана корректно, исправить запись"` (68 chars)
- **WRONG (LLM-вариант):** `КРИТИЧЕСКОЕ` — «несоответствие нормам обозначений». NO: техническое требование выполнено, ошибка в строке.

## Раздел E — ПРОВЕРИТЬ_ПО_СМЕЖНЫМ (3 примера)

### E.1 — Высота подъёмника не стыкуется с отметками АР

- **Ситуация:** В разделе подъёмник высотой 5400 мм, по отметкам АР разница ~2650 мм.
- **Категория:** `ПРОВЕРИТЬ_ПО_СМЕЖНЫМ`.
- **severity_reasoning:** `"5400 мм не стыкуется с 2650 мм — данные АР/КР для подтверждения"` (61 chars)

### E.2 — Категория помещения может конфликтовать с ПБ

- **Ситуация:** В ВК указано «насосная — категория Д», в ПБ может быть В4.
- **Категория:** `ПРОВЕРИТЬ_ПО_СМЕЖНЫМ`.
- **severity_reasoning:** `"Категория Д в ВК — нужно сверить с разделом ПБ (возможно В4)"` (60 chars)

### E.3 — full_rd: silent absence — отсутствует обязательный узел

- **Ситуация:** `full_rd`, в КЖ нет узла примыкания плиты к стене.
- **Категория:** `ПРОВЕРИТЬ_ПО_СМЕЖНЫМ`.
- **severity_reasoning:** `"Узел примыкания не показан — может быть в другом томе КЖ"` (54 chars)
- **document_type guard:** на `audit_comparison` / `specification_only` — НЕ ПОДАВАТЬ.

## Раздел F — Counter-examples (КРИТИЧЕСКОЕ → понизить)

Здесь — типичные ошибки LLM, когда ставит `КРИТИЧЕСКОЕ` на не-критическое. Должны быть понижены corrector'ом.

### F.1 — «Состав раздела ЭОМ для стадии РД/П неполный»

- **LLM поставил:** `КРИТИЧЕСКОЕ`.
- **Правильно:** на `full_rd` → `ЭКСПЛУАТАЦИОННОЕ` (отсутствие КЖ — деградация эксплуатации, не пожар). На `audit_comparison` → DO NOT REPORT (STRICT BAN).
- **Почему LLM ошибается:** воспринимает «неполный состав» как unbuildable, хотя стройка обычно возможна по чертежам.

### F.2 — «Расчёт инфильтрации не раскрыт: указан только Q_инф = 240 Вт»

- **LLM поставил:** `КРИТИЧЕСКОЕ`.
- **Правильно:** `РЕКОМЕНДАТЕЛЬНОЕ` или `ПРОВЕРИТЬ_ПО_СМЕЖНЫМ`.
- **Почему LLM ошибается:** отсутствие раскрытия расчёта ≠ ошибочный расчёт.

### F.3 — «Класс бетона по морозостойкости F и водонепроницаемости W не указаны»

- **LLM поставил:** `КРИТИЧЕСКОЕ`.
- **Правильно:** `ЭКСПЛУАТАЦИОННОЕ` (нельзя проконтролировать долговечность, но стройка возможна).
- **Почему LLM ошибается:** воспринимает любое «не указано» как блокер.

### F.4 — «Применена устаревшая редакция СП 10.13130.2009»

- **LLM поставил:** `КРИТИЧЕСКОЕ`.
- **Правильно:** `РЕКОМЕНДАТЕЛЬНОЕ`, если в новой редакции требования по сути не изменились. `КРИТИЧЕСКОЕ` — только если новая редакция требует чего-то, чего нет в проекте.
- **Почему LLM ошибается:** считает «отменённая норма» = всегда `КРИТИЧЕСКОЕ`.

### F.5 — «Стояки канализации выведены через флюгарки»

- **LLM поставил:** `КРИТИЧЕСКОЕ`.
- **Правильно:** `ЭКСПЛУАТАЦИОННОЕ` + `is_beyond_gt_useful: true`. Прямой нормы нет, но известная проблема.

### F.6 — «Раздел не содержит спецификации»

- **LLM поставил:** `КРИТИЧЕСКОЕ`.
- **Правильно (на full_rd):** `ЭКСПЛУАТАЦИОННОЕ`.
- **Правильно (на specification_only / audit_comparison):** DO NOT REPORT.
- **Почему LLM ошибается:** не смотрит на `document_type`.

## Раздел G — Severity calibration matrix (сводка)

| Дефект | Категория | Признак |
|---|---|---|
| Конкретный физический параметр нарушает СП и здание небезопасно | КРИТИЧЕСКОЕ | unbuildable / life-safety |
| Деньги/объёмы расходятся в документе | ЭКОНОМИЧЕСКОЕ | quantifiable |
| Деградация эксплуатации после сдачи | ЭКСПЛУАТАЦИОННОЕ | named consequence |
| Косметика / опечатки / наименования | РЕКОМЕНДАТЕЛЬНОЕ | стройка не блокирована |
| Нужны данные другой дисциплины | ПРОВЕРИТЬ_ПО_СМЕЖНЫМ | concrete numerical/normative conflict |
| Best-practice инженерное замечание без нормы | ЭКСПЛУАТАЦИОННОЕ + `is_beyond_gt_useful: true` | substantive concern |

## Контроль качества

- **Если КРИТИЧЕСКОЕ % > 35%** общего числа findings — пересмотри: часть из них почти наверняка должна быть `ЭКСПЛУАТАЦИОННОЕ`.
- **Если КРИТИЧЕСКОЕ без `severity_reasoning` ≤ 120 chars** — отбрасывается.
- **Если РЕКОМЕНДАТЕЛЬНОЕ применено к серьёзному дефекту** — повысь до `ЭКСПЛУАТАЦИОННОЕ` или выше.
