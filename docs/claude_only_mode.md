# Режим «только Claude»: модели по этапам конвейера

Статус: **реализован (22.10.2026), включается пресетом «Только Claude»** в окне моделей
портала. Расклад принят Андреем Ивановичем 22.10.2026. Применение режима (резерв при
недоступности Codex или замена по умолчанию) — решение за ним.

Режим: все вызовы моделей конвейера идут через Claude Code (подписка), без Codex и без
OpenRouter. Только центр: удалённым исполнителям (воркерам) пресет не выдаётся
(их список совместимых пресетов прежний; на проде `DISTRIBUTED_AUDIT_EXECUTION_ENABLED=false`).

Усилие: общее усилие Claude-вызовов с 22.10.2026 — `medium` (`AUDIT_CLAUDE_EFFORT`,
по умолчанию `medium`; было `high`). Действует и вне пресета: Claude-ветка
оптимизации в ансамбле прода и «страж отсутствия» тоже идут на medium. Claude-вызовы
воркеров — `medium` (`AUDIT_WORKER_CLAUDE_EFFORT`).

## Как устроено в коде

| Что | Где |
|---|---|
| Пресет `claude_only` (сервер / портал) | `audit_routing/presets.py`, `frontend/static/js/app.js` `modelPresets`, кнопка в `frontend/index.html` |
| Этап 01: селектор `ensemble/claude-opus-sonnet` | `config.STAGE01_CLAUDE_ONLY_*`; исполнение — `gemma_findings_only._dispatch_claude_only`; судья одной ноги — `dual_review.review_single_findings` |
| Этап 02 на Claude | `claude_runner.run_text_analysis`: промпт Codex-ветки + `claude_json_runner` со схемой `text_analysis_output_schema()`; прежний агентный путь снят |
| 03, 04, OPT, CF | штатные Claude-ветки `claude_runner` с моделью `claude-sonnet-5-5` |
| Колонка «Фактически работает» | `audit_routing/compiler.py` (действия `detector_claude_only`, `judge_claude_only`), `describe.py` |

Переменные: `STAGE01_CLAUDE_ONLY_LEG_MODEL` / `_LEG_EFFORT` (Opus 5.5 / medium),
`STAGE01_CLAUDE_ONLY_JUDGE_MODEL` / `_JUDGE_EFFORT` (Sonnet 5.5 / medium).

## Основание

### 01 Блоки — `comparison/claude_only_stage01/README.md`

Отсев 21.10 (59 блоков, все модели × усилия) и проверка 22.10 на свежих 150 блоках
(114 принятых / 101 отклонённое экспертами):

| Схема | Принятых | Отклонённых | $/блок |
|---|---:|---:|---:|
| Нынешний прод | 77 | 40 | ~0,02 Claude + ~70k ток. Codex |
| Opus medium ×2 + судья Opus | 96 / 98 | 67 / 72 | ~0,24 |
| Opus medium ×2 + судья Sonnet | 97 | 62 | ~0,16–0,24 |

Вторая нога Opus добавляет в основном средние сверки (из 50 принятых «только одной ноги» —
1 критическое), поэтому выбрана одна нога; критичное приносят основная нога и gap-search
судьи. Судья Opus на 150 блоках не лучше Sonnet. Схема «одна нога + судья» целиком не
прогонялась — перед включением нужен прогон на свежих 150 блоках.

Оценка нагрузки: ~$0,13/блок → ~13 % недели Claude в обычную неделю (2 150 блоков),
~45 % в пиковую (6 900).

### 02 Текст — `comparison/claude_only_stage02/README.md`

27 документов (228 принятых / 311 отклонённых, эталон из находок Astra):

| Модель | Принятых | Отклонённых | Замечаний | $/документ |
|---|---:|---:|---:|---:|
| Astra (прод) | 32 | 60 | 234 | Codex |
| Sonnet 5.5 medium | 99 | 144 | 636 | ~0,57 |
| Opus 5.5 medium | 132 | 168 | 453 | ~1,41 |

Выбран Sonnet (цена в 2,5 раза ниже Opus при трёхкратном выигрыше у Astra):
~3–8 % недели при 100–280 документах в неделю.

### 03 Свод, OPT, CF — `comparison/claude_only_downstream/` (22.10)

Один проход, 6 документов ЭОМ/СС; родные Claude-ветки `claude_runner` (как при выборе модели
этапа в портале), усилие medium. Выборка мала — ориентир, а не точные доли.

| Этап | Вариант | Результат | $/документ | Время, медиана |
|---|---|---|---:|---:|
| 03 Свод (сохранено из 60 принятых / 166 отклонённых) | Astra (прод) | 53 / 122 | Codex | 406 с |
| | Sonnet medium | **60** / 146 | 0,90 | 214 с |
| | Opus medium | 59 / 146 | 1,96 | 327 с |
| OPT (совпало с 26 принятыми / 102 отклонёнными прод-ансамбля) | Sonnet medium | 10 / 30 | 0,53 | 140 с |
| | Opus medium | 11 / 28 | 1,73 | 322 с |
| CF критик (принятые пропущены / отклонённые забракованы) | Astra (прод) | 26 из 26 / 3 из 102 | Codex | 81 с |
| | Sonnet medium | 20 из 26 / 27 из 102 | 0,46 | 78 с |
| | Opus medium | 21 из 26 / 30 из 102 | 1,06 | 141 с |

Свод теряет принятые реже у Claude; Sonnet не хуже Opus вдвое дешевле. OPT: одна нога
находит ~40 % принятого прод-ансамблем, Sonnet ≈ Opus при цене ×3,3 ниже. Критик Astra
пропускает почти всё; Claude бракует ~27–30 % отклонённого ценой 5–6 из 26 принятых.

## Что ещё не проверено

1. Связка этапа 01 «одна нога Opus + судья Sonnet» целиком не прогонялась на эталоне
   (качество выведено из частей); судья одной ноги — новый промпт без сравнения ног.
2. Этап 04 (агентный путь с MCP норм) и правщик CF на Sonnet.
3. Квота: при исчерпании лимита Claude в этом режиме встают все этапы — Codex-резерва нет.
