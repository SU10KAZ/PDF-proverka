# Выделение источника ProjectChange

Кнопка «Лист с выделением» открывает исходную страницу PDF и цитату сохранённого
результата. URL привязан к объекту, сессии, паре и прогону; изменённый после
проверки источник недоступен через этот просмотр.

- Сплошная красная рамка обозначает уникально найденную последовательность слов
  цитаты в текстовом слое PDF внутри сохранённого блока источника.
- Для цитат с многоточиями выделяются найденные содержательные части; интерфейс
  сообщает, что полное совпадение не установлено.
- Если совпадения нет, оно неоднозначно или у PDF нет текстового слоя, пунктирная
  рамка обозначает сохранённый блок, а сообщение объясняет ограничение.
- Для GRAPHIC рамка обозначает сохранённую область чертежа. Без координат
  показывается лист целиком без рамки.

Поиск локальный и детерминированный, без OCR и запросов к моделям. Он не меняет
результат проверки, исходные PDF или сохранённые фрагменты. Геометрия рамок
учитывает поворот страницы; изображение и рамки используют единую систему
координат SVG. Старые результаты без нового URL открывают прежний фрагмент.

Проверки: `backend/tests/project_change_v3/test_evidence_page.py` и
`frontend/tests/project_change_evidence_page.test.js`.
