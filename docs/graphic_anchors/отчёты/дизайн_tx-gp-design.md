## 0. Сквозные эмпирические факты (ломают/подтверждают гипотезы)

1. **`dashes` пуст во всех 12 проверенных PDF** (ТХ×6, ГП×6). Штрихпунктир осевых/центровых экспортируется цепочками коротких `"l"`-сегментов → детектор осевой линии строить как «коллинеарную цепочку коротких сегментов с периодом», НЕ по ключу dashes (правит план из vector-paths-drawings.md §4 п.3: `width` жив, `dashes` — нет).
2. **Засечки размерных линий существуют и стандартизованы**: короткие штрихи под 45°, доминантные длины **2.0 pt** (план шахт ТХ-010: 1418 шт), **2.8–2.9 pt** (разрез ТХ-017), **1.8–1.9 pt** (узел ТХ-024). Fill-стрелок у размеров нет (fill-сливеры не у чисел: медиана дистанции 121 pt).
3. **Размерная цепочка читается**: линия + ≥2 засечки на ней + число в пролёте. ТХ-024: 14/20 чисел в 20 pt от засечки, масштаб пролётов согласован (3.52–3.53 мм/pt); ТХ-017: 1600/62.6 pt = 25.0–25.6 мм/pt стабильно. Анти-пример: ГП-013 (сечение схода) даёт 15860 ложных «засечек» от 45°-штриховки и 0 совпадений с числами → **гейт цепочки = согласованность масштаба пролётов**, а не наличие засечек.
4. **Осевой кружок = path из 2–4 `"c"`-items, Ø13–26 pt, ровно одно слово внутри**: ТХ-030 — 30/38 кружков Ø16.9 с маркой («П.13», «5.Т», «3.7»); ТХ-010 — Ø19.8×39 + Ø16.9×30; ТХ-034 — эллипсы (23.5×16.7)×96 в неповёрнутых координатах. Заменяет чисто текстовый `_axes` (hvac_geometry.py:219, даёт ложную ось «1000»).
5. **Стрелка уклона на планах ГП = цепочка коллинеарных тонких заливок** ~10.2×0.5–0.6 pt с шагом ~17 pt (штриховой вал), наконечники — заливки 2.9×3.4; над валом **целое число = уклон в промилле** (dy≈−4.8), под ним **число с дробью = длина** (dy≈+7.1): `arrow@(1370,537): '5' d=4.8 выше, '20.79' d=7.1 ниже`. Текстовые формы `i=`/`‰` в корпусе ГП **не встречаются вообще** (regex `slope` в PATTERNS :52 мёртв — подтверждён «uklony=0» из coverage-аудита).
6. **Пара «красная/чёрная отметка»**: два NN,NN в стек (|Δx|<12, Δy≈10.3 pt) + разделительная черта между ними — 71/77 пар на рельефе ГП-014. Черта = дискриминатор от ложных пар (отметка+длина без черты).
7. **Флажок отметки — текст-глиф `▐`** (символьный CAD-шрифт): 96 шт на рельефе, 96 на МАФ, сотни на раскладке покрытий. Якорь нулевой стоимости, median дистанции до отметки 30.8 pt (окно привязки ~40 pt вдоль строки чтения).
8. **Повороты**: у ~половины эталонов `rot=270`; «строка чтения» на GP-ROAD идёт вдоль X в display-space. Ось порядка слоёв = перпендикуляр к направлению чтения слов (из `span["dir"]`), а не безусловный Y. Клип: `get_text` режется cropbox'ом, `get_drawings` — НЕТ (на ТХ-010 кружки за кропом остались без слов) → клип drawings по cropbox обязателен (fail-closed, как `_clip_words_to_bbox` G:125).

## 1. НОВЫЕ ПРИМИТИВЫ общей библиотеки (ярус B, один модуль `construction_anchor_primitives.py` рядом с `vector_path_graph.py`)

| Примитив | Вход→выход | Эмпирические константы |
|---|---|---|
| `detect_dim_ticks(drawings)` | 45°-штрихи 1.0–3.5 pt → список засечек | длины 1.8–2.9 pt, угол 30–60° |
| `dim_chains(lines, ticks, num_words)` | линия+засечки → пролёты, число в пролёте (|Δc|<max(6, 0.25·span), поперёк ±14 pt) | гейт: median-масштаб мм/pt, отклонение пролёта >20% → drop цепочки |
| `slope_arrow(fill_paths)` | цепочка коллинеарных заливок len 8–16×≤0.7, шаг 15–20 → вал+направление по наконечнику 2.9×3.4 | уклон = целое сверху ≤8 pt, длина = дробное снизу ≤10 pt |
| `axis_bubble(drawings, words)` | c-path Ø13–26, aspect 0.85–1.18, ровно 1 слово внутри → осевая марка с центром | Ø16.9/19.8/22.7; ≥75% кружков с маркой = сетка осей валидна |
| `stacked_pair(words, hsegs)` | стек NN,NN + черта 6–45 pt между → узел «двойная отметка» | Δy 4–16 (медиана 10.3), |Δx|<12 |
| `flag_glyphs(words)` | `▐▌►◄` → точки-носители отметок | связь с ближайшей отметкой вдоль строки чтения ≤40 pt |
| `line_grid(lines)` | кластеры длинных V/H линий → сетка ячеек, слово→ячейка | профили/земляные массы/таблицы; замыкает разрыв «grid-line-парсера нет» (vector-paths §2) |
| `collinear_dash_chain(segments)` | периодическая цепочка коротких сегментов → осевая/штрихпунктир | замена мёртвого dashes |
| `reading_line_pair(atoms)` | пара «имя↔значение» в одной строке чтения, поперечный сдвиг ≤9 pt | rotation-aware, поверх `block_text_clustering.line_atoms` :68 |

Всё связывание — существующими `_attach` (general_plan_geometry.py:106), `_components` (hvac_geometry.py:170), `_near` (G:226), допуски в долях медианного шага (урок Вектографа).

### gp_road_structure — конструкция дорожной одежды (24 блока — самый массовый профиль)
