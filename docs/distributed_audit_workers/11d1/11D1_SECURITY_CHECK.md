## 2. Правки 11D.1 — что именно добавлено в промпт

Две константы-литерала:

1. `SEVERITY_SEMANTICS` — 652 символа. Содержит только названия пяти категорий и
   их определения. Ни путей, ни имён файлов, ни данных заказчика, ни ссылок на
   `CLAUDE.md`.
2. Уточнение одной фразы `TRANSPORT_CONTRACT` — 163 символа. Текст про доступ к
   инструментам.

Обе — статические строки в исходнике. Никакого чтения файлов, никакой сети,
никакого нового источника контекста. Проверено тестом
`test_q_personal_context_stays_excluded`.

Что **не** сделано и не будет: не возвращены `Read`/`Write`/`Bash`/`Grep`/`Glob`,
не возвращены `--setting-sources`, не возвращён проектный `CLAUDE.md`, не
добавлены хуки, MCP и навыки.

## 3. Диагностические артефакты не содержат документа заказчика

Сырьё (полные промпты обоих путей, полный MD) собрано во **временный** каталог
вне репозитория:
`/tmp/claude-1001/…/scratchpad/11d1/raw/` — **в git не попадает**.

В `docs/distributed_audit_workers/11d1/` уезжают только метрики, хэши,
имена секций и короткие технические фрагменты.

Проверка выполнена грепом по каталогу артефактов семью характерными
словосочетаниями из тела документа (опечатки OCR, обозначения оборудования,
марки материалов; сами слова здесь не приводятся, чтобы отчёт не стал ещё одной
копией фрагментов):

| проверка | результат |
|---|---|
| характерные фрагменты текста документа | **0 вхождений** (единственное исключение — §5 ниже) |
| полный MD или его абзацы | **0** |
| полный текст промпта | **0**; есть отдельные строки шаблона и правил, но они и так лежат в репозитории |
| абсолютные пути домашних каталогов | нет; в артефактах только относительные пути внутри репозитория |
| учётные данные, токены, адреса центра | **0** |

## 5. Единственное сознательное исключение

`11D1_THREE_FINDINGS_TRACE.md` цитирует **одну строку MD** (~130 символов) —
ту, где стоит ссылка «ПУЭ п.7.35». Без неё нельзя показать, что исходное условие
для первой из трёх тем в документе действительно есть, а §12 требует именно
такой трассы. Это короткий технический фрагмент, прямо разрешённый §6 задания.
Больше ни одна цитата из тела документа в артефакты не попала: темы B и C
доказываются **отсутствием** совпадений, для чего цитировать нечего.

`11D1_HISTORICAL_BASELINE_PROVENANCE.json` содержит счётчики, ключи и
распределение severity исторического результата, но **не** тексты замечаний.
