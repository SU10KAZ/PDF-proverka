Условия: действующий корневой `.env` от 2026-08-10.

## Сводка: где пресеты реально расходятся

Из 10 строк UI различие есть только в **пяти**, и все — смена провайдера
одного текстового этапа:

1. 02 Текст — Opus 5 ↔ Codex
2. 03 Свод — Opus 5 ↔ Codex **(+2…4 дополнительных вызова у Codex)**
3. 04 Нормы — только шаг привязки пунктов, Opus 5 ↔ Codex
4. 04b Пересмотр — Opus 5 ↔ Codex
5. C OPT Critic — Sonnet 5 ↔ Codex

Строки **01 Блоки, Верификатор, Верификатор (фикс), 05 Оптимизация, F OPT Fix**
работают в двух пресетах **одинаково**. Из них три (Верификатор, Верификатор (фикс),
F OPT Fix) вообще не читают выбранную модель.

## Разница в стоимости (в вызовах модели, документ на B блоков)

| | Claude+GPT+Codex | Full Codex |
|---|---|---|
| Фиксированные вызовы (без условных) | 4 | 5…7 |
| На блок | 4 | 4 |
| Итого при B=40 | ≈164 | ≈165…167 |

Обе конфигурации на 96 % состоят из этапа 01. Смена пресета почти не меняет
расход подписки — она меняет **чем** сделаны текстовые этапы, а не сколько их.
