## 2. Отдельный 11E-рантайм (§20 задания)

Существующая установка воркера и рантаймы 11D / 11D.2 **не тронуты**. 11E живёт
в собственном корне:

```
~/audit-worker-11e/
  app/<release>/                      ← распакованный артефакт
  current -> app/<release>
  data/                               ← корень данных 11E (политика, разрешения)
  inputs/                             ← копии входов свода (4 файла)
  prompts/prompts_snapshot/           ← снимок промптов + профиль ЭОМ
  sandbox/<task_id>/                  ← каталоги попыток
  tools/                              ← прогонный скрипт, гейт, сверка смысла, сборщик доказательств
  logs/                               ← отчёты гейтов, снимок дерева процессов
  incoming/                           ← доставленные артефакты релиза
```

Указать `--worker-root` в чужой рантайм нельзя: прогонный скрипт отказывается
стартовать, если путь ведёт в `~/audit-worker`, `~/audit-worker-11d` или
`~/audit-worker-11d2`.

Python берётся из venv существующей установки (`~/audit-worker/venv/bin/python`,
3.12.3) — **на чтение**. Второй venv не создавался: ставить зависимости из сети
на чужую машину ради одного прогона незачем.
