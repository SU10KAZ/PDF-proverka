# 11G — развёртывание воркера на 176.12.77.31

## 1. Способ

Детерминированный артефакт, а не `rsync` правленых файлов
(`scripts/deploy_audit_worker.py`, §16 задания). Доставка идёт по SSH —
административный канал; заданий, результатов и обращений к модели этот канал
не переносит ни в одном режиме.

```
python scripts/deploy_audit_worker.py deploy \
  --host 176.12.77.31 --user coder \
  --remote-root /home/coder/audit-worker-11g \
  --pipeline-revision 11g --source-commit <HEAD>
```

## 3. Изоляция экземпляра (§15)

Корень `/home/coder/audit-worker-11g` — отдельный от продовой установки

`logs/`, релизы, venv.

### Дефект, найденный этим же развёртыванием

Первое развёртывание в новый корень **перезапустило юниты СТАРОЙ установки**:
имена юнитов были константами (`audit-worker-agent.service`), а корень —
параметром. Фактический эффект на .31: поднялся агент установки этапа 11,
читающий `/home/coder/audit-worker/config/worker.env` с адресом давно закрытого
туннеля. Вреда не случилось по счастливой случайности — у той установки
настоящие модели выключены, а адрес мёртв.

Исправлено в `deploy_audit_worker.units_for_root` и
`smoke_distributed_audit_real_vps.unit_names`: имена выводятся из корня.
Корень `…/audit-worker` сохраняет прежние имена дословно, любой другой получает
свою пару:

```
audit-worker-11g-agent.service
audit-worker-11g-executor.service
```

Юниты старой установки остановлены обратно в то состояние, в котором были
(`inactive`, последний штатный останов — 09.08).

## 4. Что НЕ трогалось

* почтовый и Plesk-стек машины;
* firewall, sshd, системный systemd (юниты — пользовательские);
* корни и данные прошлых этапов;
* входящих портов не открыто ни одного: транспорт — исходящий HTTPS воркера.

## 5. Откат

```
python scripts/deploy_audit_worker.py rollback --host 176.12.77.31 --user coder \
  --remote-root /home/coder/audit-worker-11g --to 20260810T112228-6e1fac79ab71
```

Откат — переключение симлинка `current`, а не восстановление из копии: код и
данные разведены, `data/` при смене релиза не трогается.
